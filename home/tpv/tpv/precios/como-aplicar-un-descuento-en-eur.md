# Cómo aplicar un descuento en €

Desde el TPV es posible aplicar un descuento directo en euros sobre una venta antes de realizar el cobro. Esta opción resulta útil cuando el club necesita ajustar el importe final por una promoción, una atención comercial, una corrección puntual o cualquier otra situación en la que sea necesario descontar una cantidad concreta.

A continuación, te mostramos cómo aplicar un descuento en euros paso a paso.

{% stepper %}
{% step %}
### Acceso al TPV

* Dirígete al menú lateral izquierdo y selecciona **TPV**, o haz clic sobre la reserva correspondiente y selecciona **Pagar reserva**. Ambas opciones te llevarán al TPV.
{% endstep %}

{% step %}
### Búsqueda de jugador o cliente

*   Si no estás pagando una reserva y no has seleccionado previamente al jugador, utiliza el buscador situado en la esquina superior derecha para localizarlo.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   Si se trata de una venta ocasional y no se registrarán datos, selecciona **Cliente anónimo**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Seleccionar el producto

* Si no es una reserva, elige el producto que deseas vender desde la lista disponible.
{% endstep %}

{% step %}
### Aplicar descuento

* Introduce en el teclado del TPV la cantidad en euros que deseas descontar y pulsa el símbolo **€** para aplicar el descuento automáticamente.
* Por ejemplo, si quieres descontar **5 €**, introduce `5` en el teclado del TPV y pulsa **€**.\
  ![](<../../.gitbook/assets/image (36).png>)
* El descuento se aplicará directamente sobre el importe del ticket.
{% endstep %}

{% step %}
### Verificar y cobrar

* Comprueba que el descuento se ha reflejado correctamente en el ticket y procede al cobro con el método de pago elegido por el cliente.\
  ![](<../../.gitbook/assets/image (37).png>)
{% endstep %}
{% endstepper %}

Una vez aplicado el descuento y realizado el cobro, la venta quedará registrada con el importe final correspondiente. Utilizar correctamente esta opción permite ajustar precios de forma puntual y controlada, manteniendo el ticket y el cierre de caja correctamente reflejados en el sistema.
