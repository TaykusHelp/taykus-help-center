# Cómo aplicar un descuento en %

Aplicar descuentos desde el TPV permite ajustar el importe de una venta de forma rápida y controlada, ya sea por promociones, incidencias o atención comercial. A continuación te mostramos cómo aplicar un descuento paso a paso.

{% stepper %}
{% step %}
### Acceso al TPV

* Dirígete al menú lateral izquierdo y selecciona **TPV**, o haz clic sobre la reserva correspondiente y selecciona **Pagar reserva**. Ambas opciones te llevarán al TPV.
{% endstep %}

{% step %}
### Búsqueda de jugador o cliente

*   Si no estás pagando una reserva y no has seleccionado previamente al jugador, utiliza el buscador situado en la esquina superior derecha para localizarlo.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   Si se trata de una venta ocasional y no se registrarán datos, selecciona **Cliente anónimo**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Seleccionar el producto

* Si no es una reserva, elige el producto que deseas vender desde la lista disponible.
{% endstep %}

{% step %}
### Aplicar descuento

*   Introduce en el teclado del TPV el porcentaje de descuento que deseas aplicar y pulsa el símbolo **%** para que se aplique automáticamente.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Verificar y cobrar

*   Comprueba que el descuento se ha reflejado correctamente en el ticket y procede al cobro con el método de pago elegido por el cliente.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

Una vez aplicado el descuento, la venta continuará con normalidad. Utilizar esta función de forma correcta garantiza que los ajustes de precio queden registrados y evita errores en el cierre de caja.
