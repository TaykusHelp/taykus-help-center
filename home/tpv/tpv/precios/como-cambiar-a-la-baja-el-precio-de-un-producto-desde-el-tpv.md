# Cómo cambiar a la baja el precio de un producto desde el TPV

Reducir el precio de un producto desde el TPV permite ajustar una venta puntual sin modificar el precio general del artículo en el sistema. Esta opción es útil para aplicar ajustes comerciales o resolver incidencias durante el cobro. A continuación te explicamos cómo hacerlo paso a paso.

{% stepper %}
{% step %}
### Acceso al TPV

* Dirígete al menú lateral izquierdo y selecciona **TPV**, o haz clic sobre la reserva correspondiente y selecciona **Pagar reserva**. Ambas opciones te llevarán al TPV.
{% endstep %}

{% step %}
### Búsqueda de jugador o cliente

*   Si no estás pagando una reserva y no has seleccionado previamente al jugador, utiliza el buscador situado en la esquina superior derecha para localizarlo.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   Si se trata de una venta ocasional y no se registrarán datos, selecciona **Cliente anónimo**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Seleccionar el producto

* Si no es una reserva, elige el producto que deseas vender desde la lista disponible.
{% endstep %}

{% step %}
### Cambiar precio

* Haz clic sobre el nombre del producto en el ticket.
*   La línea se resaltará en color verde y podrás introducir el nuevo precio.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (24).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Verificar y cobrar

*   Comprueba que el nuevo precio se ha reflejado correctamente en el ticket y procede al cobro con el método de pago elegido por el cliente.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure></div>
* El nuevo precio se reflejará en el ticket como un descuento aplicado sobre el importe original.
{% endstep %}
{% endstepper %}

Una vez modificado el precio, podrás continuar la venta con normalidad. Este ajuste quedará registrado en el ticket como descuento, garantizando que el movimiento quede reflejado correctamente en caja.
