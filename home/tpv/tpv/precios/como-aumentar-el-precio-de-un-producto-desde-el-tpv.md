# Cómo aumentar el precio de un producto desde el TPV

El TPV permite modificar el precio de un producto únicamente a la baja. Si necesitas aumentar el importe de una venta puntual, puedes hacerlo añadiendo un producto abierto con la diferencia.

En el siguiente video podrás visializar como:

### Video Explicativo

{% embed url="https://youtu.be/X6QTBKdHrGs" %}

A continuación te explicamos cómo subir el importe de un ticket paso a paso:

{% stepper %}
{% step %}
### Acceso al TPV

* Dirígete al menú lateral izquierdo y selecciona **TPV**, o haz clic sobre la reserva correspondiente y selecciona **Pagar reserva**. Ambas opciones te llevarán al TPV.
{% endstep %}

{% step %}
### Búsqueda de jugador o cliente

*   Si no estás pagando una reserva y no has seleccionado previamente al jugador, utiliza el buscador situado en la esquina superior derecha para localizarlo.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   Si se trata de una venta ocasional y no se registrarán datos, selecciona **Cliente anónimo**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Seleccionar el producto

* Si no es una reserva, elige el producto que deseas vender desde la lista disponible.
{% endstep %}

{% step %}
### Añade un producto abierto

*   Haz clic sobre el **Precio Abierto.**<br>

    <figure><img src="../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>
* Emerge la siquiente ventana a completar.
*

    <figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>

    * **Descripción:** introduce el nombre o motivo del aumento de precio. Este texto será el que aparecerá reflejado en el ticket.
    * **Precio:** introduce el importe que deseas añadir al ticket.
    * **Tipo de producto:** selecciona en el desplegable una categoría si deseas clasificar este producto abierto. Este campo es opcional.
    * **Impuestos:** selecciona el tipo de impuesto a aplicar a este producto abierto.
* Clica **OK** para añadir este cargo al ticket.
{% endstep %}

{% step %}
### Verificar y cobrar

*   Comprueba que el nuevo precio se ha reflejado correctamente en el ticket y procede al cobro con el método de pago elegido por el cliente.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

Añadir un producto abierto permite ajustar el importe final sin modificar el precio base del artículo en el sistema. De esta forma, el ajuste queda registrado correctamente en el ticket y en el control de caja.
