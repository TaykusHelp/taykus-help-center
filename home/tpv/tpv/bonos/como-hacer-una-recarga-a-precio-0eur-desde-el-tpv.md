# Cómo hacer una recarga a precio 0€ desde el TPV

Personalizar una recarga a precio 0 € permite añadir saldo a un bono monedero sin generar cobro, por ejemplo en casos de cortesía, compensaciones o ajustes internos. Esta operación queda registrada en el sistema y mantiene el historial del bono actualizado.&#x20;

A continuación te explicamos cómo hacerlo paso a paso.&#x20;

{% stepper %}
{% step %}
### Acceso al TPV

* Dirígete al menú lateral izquierdo y selecciona **TPV.**
{% endstep %}

{% step %}
### Búsqueda de jugador o cliente

*   Utiliza el buscador ubicado en la esquina superior derecha para localizar al jugador deseado.

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Selección de Bono

*   Haz clic en la opción de Bonos, situada bajo los elementos de acceso rápido.

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Personalización de la recarga

* Se abrirá una ventana con todos los bonos disponibles.
* Selecciona **cualquiera de los bonos** previamente configurados.

<figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

* Clica en personalizar recarga.
*   Se abrirá un desplegable con las características del bono seleccionado que podrás modificar.

    <figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure>
* **Personalizar Recarga:**
  * **Precio:** escribe cero con números.
  * **Tipo de bono:** selecciona en el desplegable el tipo de bono correspondiente.
  * **Tipo de cantidad:** elige en el desplegable el tipo de saldo que se va a recargar.
  * **Cantidad a recargar:** introduce la cantidad que deseas añadir (por ejemplo, 100 € o 10 unidades).
  * **Descripción:** comentario opcional para indicar el motivo de la recarga personalizada.
* **Personalizar Restricciones:**
  * Esta sección no es obligatoria pero se pueden personalizar las restricciones del bono.
* Clica OK para guardar la personalización.
{% endstep %}

{% step %}
### Finalizar la recarga

* Este paso es imprescindible. Aunque el precio sea 0 €, la recarga no se registrará si no se confirma la operación.
*   Haz clic en **Confirmar.**<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure></div>
* El ticket pasará a estado **Pagado** confirmando que la recarga se ha realizado correctamente.\
  ![](<../../.gitbook/assets/image (10).png>)
{% endstep %}
{% endstepper %}

Una vez confirmada la recarga a 0 €, el saldo quedará disponible de inmediato sin generar movimiento de cobro. Registrar estas operaciones correctamente garantiza trazabilidad y control en el historial del bono.
