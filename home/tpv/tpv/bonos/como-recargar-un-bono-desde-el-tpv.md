# Cómo recargar un bono desde el TPV

Recargar un bono monedero desde el TPV permite añadir saldo de forma inmediata para que el cliente pueda utilizarlo en futuras compras o reservas. Este proceso queda registrado automáticamente en el sistema y facilita la gestión de pagos anticipados.&#x20;

A continuación, se explica cómo realizar una venta con un producto abierto:

{% stepper %}
{% step %}
### Acceso al TPV

* Dirígete al menú lateral izquierdo y selecciona **TPV**.
{% endstep %}

{% step %}
### Búsqueda de jugador o cliente

*   Utiliza el buscador ubicado en la esquina superior derecha para localizar al jugador deseado.

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Selección de Bono

*   Haz clic en la opción de Bonos, situada bajo los elementos de acceso rápido.<br>

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Selección de bono deseado

* Se abrirá una ventana con todos los bonos disponibles.
* Selecciona el bono que deseas recargar entre los previamente configurados.

<figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

* Si necesitas hacer alguna modificación específica para este cliente, puedes **Personalizar la recarga,** para saber como haz clic en el siguiente enlace:\
  [como-hacer-una-recarga-personalizada-de-un-bono-monedero-desde-el-tpv.md](como-hacer-una-recarga-personalizada-de-un-bono-monedero-desde-el-tpv.md "mention")<br>
{% endstep %}

{% step %}
### Finalizar la recarga

* Procede al cobro, utilizando el método de pago preferido por el cliente.
* Si la recarga del bono queda pendiente de pago o domiciliación, el saldo no se le recarga al cliente hasta que quede abonada.
{% endstep %}
{% endstepper %}

Una vez realizada la recarga, el saldo quedará disponible de inmediato para su uso. Registrar correctamente estas operaciones garantiza un control preciso del monedero y de los movimientos en caja.
