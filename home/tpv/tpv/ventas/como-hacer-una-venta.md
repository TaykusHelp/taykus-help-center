# Cómo hacer una venta

El TPV permite registrar ventas de productos y servicios de forma rápida y segura, asegurando que todos los movimientos queden correctamente reflejados en caja. Aunque el proceso es sencillo, es importante seguir los pasos adecuados para evitar errores en cobros o descuadres.

En este artículo explicamos cómo realizar una venta desde el TPV paso a paso.



{% stepper %}
{% step %}
### Acceso al TPV

* Dirígete al menú lateral izquierdo y selecciona **TPV**.
{% endstep %}

{% step %}
### Búsqueda de jugador o cliente

*   Utiliza el buscador situado en la esquina superior derecha para localizar al cliente al que se le va a realizar la venta.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>
*   Si se trata de una venta ocasional y no se registrarán datos, selecciona **Cliente anónimo**.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Seleccionar el producto

* Selecciona el producto que deseas vender desde la lista disponible.
*   Los artículos marcados como **Venta rápida** aparecerán directamente en esta pantalla, donde está señalando en la imagen.

    <figure><img src="../../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>
*   También puedes localizarlos seleccionando el **tipo de producto** asociado. Al hacer clic sobre el nombre del tipo, se desplegarán todos los artículos vinculados a esa categoría..

    <figure><img src="../../.gitbook/assets/image (34).png" alt=""><figcaption></figcaption></figure>


*   Otra opción es utilizar el **buscador de productos**. Haz clic en el buscador y escribe el nombre del producto o el número del código de barras si ha sido registrado previamente.

    <figure><img src="../../.gitbook/assets/image (35).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Verificar y cobrar

* Revisa que todos los artículos deseados aparecen correctamente en el ticket.
*   Una vez confirmado, selecciona el método de pago elegido por el cliente y procede a finalizar la venta.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}
{% endstepper %}

Realizar correctamente una venta desde el TPV garantiza que los cobros queden registrados de forma precisa y evita descuadres en caja. Antes de finalizar cualquier operación, revisa siempre el ticket para asegurarte de que los artículos y el importe son correctos.
