# Cómo anular una venta desde el TPV

La opción **Anular venta** en el TPV permite cancelar operaciones registradas por error y mantener el control correcto de la caja. Esta funcionalidad resulta especialmente útil cuando se ha cobrado un importe incorrecto, se ha seleccionado un producto equivocado o es necesario revertir una venta antes del cierre. Anular desde el propio TPV garantiza que el movimiento quede reflejado de forma ordenada en el sistema y evita descuadres posteriores.

En este artículo te mostramos cómo hacerlo paso a paso.

{% stepper %}
{% step %}
### Localiza la venta

* Es posible localizar la venta desde el propio TPV, desde el calendario o desde **Líneas de venta**.
* Una vez localizada, ábrela en el TPV.
{% endstep %}

{% step %}
### Anular Venta

*   Haz clic en **Anular venta**.

    <figure><img src="../../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>
*   Antes de confirmar, el sistema mostrará un aviso de verificación.

    <figure><img src="../../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
* Pulsa **Sí** para completar la anulación.
{% endstep %}

{% step %}
### Comprobación

*   Tras anular la venta, puedes verificar que el proceso se ha realizado correctamente comprobando que el ticket aparece a **0 €** y tachado.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure></div>


*   Al salir del TPV el sistema redirige automáticamente a **Líneas de venta**, donde la operación se mostrará en **rojo**, indicando que ha quedado registrada como anulada.<br>

    <figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

Esta revisión rápida confirma que el movimiento se ha guardado correctamente en el sistema.
