# Cómo abrir la caja desde el TPV

Abrir la caja desde el TPV permite registrar el importe inicial con el que comienza la jornada y garantizar un control correcto de los movimientos de efectivo. Realizar este paso al inicio del día ayuda a evitar descuadres y mantiene el seguimiento de caja organizado. En este artículo te mostramos cómo hacerlo paso a paso.

{% stepper %}
{% step %}
### **Accede al TPV**

* Dirígete al menú lateral izquierdo y selecciona **TPV.**
{% endstep %}

{% step %}
### Selección de caja

* Si la caja está cerrada, al acceder al TPV aparecerá automáticamente una ventana con las cajas disponibles.
*   Haz clic en la caja que se desea abrir.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Abrir caja

* Tras seleccionar la caja, el sistema te redirigirá a la página de resumen de caja.
*   Selecciona **Movimientos.**<br>

    <figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>
* Sino se desea abrir con nada de efectivo registrado en el sistema, dejar en blanco.
* Clica en OK para abrir la caja.
{% endstep %}

{% step %}
### Indicar fondo de caja

* Se abrirá una ventana en la que debes introducir el efectivo inicial con el que deseas abrir la caja.\
  ![](<../../.gitbook/assets/image (18).png>)
* Si no quieres registrar efectivo inicial, deja el campo en blanco.
{% endstep %}

{% step %}
### Confirmar apertura

* Clica en <mark style="color:$tint;">**OK**</mark> para abrir la caja
{% endstep %}
{% endstepper %}

Una vez abierta la caja, ya podrás comenzar a registrar ventas y movimientos con normalidad. Recuerda realizar siempre la apertura al inicio de la jornada para mantener un control correcto del efectivo y evitar descuadres al cierre del día.
