# Cómo aparcar una venta

La función de aparcar una venta en el TPV permite pausar una transacción en curso para atender a otro cliente y retomarla más tarde sin perder la información. Es una herramienta útil para gestionar momentos de alta actividad en caja. A continuación te explicamos cómo utilizarla paso a paso.

### ¿Cómo aparcar una venta?

Si ya tienes el TPV abierto con un producto, ya sea desde una reserva (accediendo al TPV desde el calendario) o desde una venta directa, sigue estos pasos:

{% stepper %}
{% step %}
### **Aparcar la venta**

*   En la parte superior de la pantalla del TPV, haz clic en **Aparcar venta**.<br>

    <figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### **Confirmación**

* La venta quedará aparcada automáticamente.
*   El ticket pasará de color verde a blanco, indicando que el TPV vuelve a estar disponible para realizar otra operación.<br>

    <figure><img src="../../.gitbook/assets/image (15).png" alt=""><figcaption></figcaption></figure>


{% endstep %}
{% endstepper %}

Una vez aparcada la venta, quedará guardada en el sistema hasta que decidas retomarla. Esta función permite liberar el TPV sin perder la transacción en curso y facilita la gestión de varios clientes durante momentos de mayor actividad.
