# Cómo cambiar de usuario a través del TPV

**Cambiar de usuario** en el TPV permite alternar rápidamente entre empleados cuando un mismo terminal es utilizado por varias personas. Esta función asegura que cada operación quede registrada bajo el usuario correcto, facilitando el control de ventas y el seguimiento de la actividad en caja sin necesidad de cerrar sesión ni interrumpir el flujo de trabajo.

En este artículo te mostramos cómo utilizar esta opción paso a paso.

{% stepper %}
{% step %}
### Acceso al TPV

* Dirígete al menú lateral izquierdo y selecciona **TPV.**
{% endstep %}

{% step %}
### Cambio de usuario

*   Clica en el botón **Cambio de usuario.**

    <figure><img src="../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Selección de usuario

*   Se abre una ventana con todos los usuarios disponibles.<br>

    <figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>
* Clica sobre el usuario deseado.
* Se abre otra ventana para introducir la contraseña.

<div align="left"><figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure></div>

* Clica OK para hacer el cambio de usuario.
{% endstep %}
{% endstepper %}

Usar correctamente la función **Cambiar de usuario** ayuda a mantener un registro ordenado de la actividad en el TPV y garantiza que cada operación quede asociada a la persona correspondiente. Integrar este hábito en el trabajo diario mejora el control de caja y evita confusiones entre turnos.
