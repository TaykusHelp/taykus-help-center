# Cómo recuperar una venta aparcada

Recuperar una venta aparcada permite retomar una transacción pausada sin perder la información registrada previamente. Esta función es útil para continuar el cobro cuando un cliente regresa o cuando se ha interrumpido una operación en caja. A continuación te mostramos cómo recuperar una venta aparcada paso a paso.

{% stepper %}
{% step %}
### Acceso al TPV

* Dirígete al menú lateral izquierdo y selecciona **TPV**.
{% endstep %}

{% step %}
### Abrir ventas aparcadas

*   En la parte superior de la pantalla, haz clic en **Ventas aparcadas**.<br>

    <figure><img src="../../.gitbook/assets/image (16).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Seleccionar la ventana

* Se abrirá una ventana con todas las ventas aparcadas.
*   Elige la venta que deseas retomar.<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Finalizar la venta

* Continúa con el cobro utilizando el método de pago que prefiera el cliente.
{% endstep %}
{% endstepper %}

Una vez recuperada la venta, podrás finalizar el cobro con normalidad. Utilizar correctamente las ventas aparcadas ayuda a mantener el orden en el TPV y evita pérdidas de información durante la jornada.
