# Cómo crear una plantilla

Las plantillas de email permiten crear mensajes reutilizables para agilizar el envío de comunicaciones y mantener un formato uniforme.

En este artículo te mostramos cómo crear una nueva plantilla de correo en Taykus y configurar su contenido para utilizarla posteriormente en tus comunicaciones.
