# Cómo crear una petición de stock

En este artículo, te explicamos paso a paso cómo utilizar el módulo de almacén. Gracias a un sistema intuitivo y eficiente, podrás llevar un control preciso del stock disponible, gestionar entradas y salidas de productos, y mantener actualizada la información en tiempo real. Este proceso no solo optimiza la organización interna, sino que también facilita la toma de decisiones y evita faltantes o excesos en el inventario.

A continuación, te explicamos cómo hacerlo:

{% stepper %}
{% step %}
### Acceso a Almacén

* Dirígete a la columna de la izquierda y selecciona **Almacén**.
* Se abrirá la sección donde se encuentran todas las peticiones de stock.
{% endstep %}

{% step %}
### Crear nueva petición de stock

* Haz clic en :heavy\_plus\_sign: para crear una nueva.
*   Se abrirá un breve formulario que se deberá completar con los siguientes datos:

    <figure><img src="../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

    * **Descripción:** Especifica el nombre el pedido/petición. Te recomendamos incluir la fecha.
    * **Comentarios:** Espacio para añadir una descripción adicional.
    * **Validado:&#x20;**<mark style="background-color:$warning;">**IMPORTANTE.**</mark> El pedido debe llevar este check para, en el siguiente paso, poder añadir stock.
* Clica Guardar para salvar la petición.
{% endstep %}

{% step %}
### Añadir productos

* Al guardar, el programa te redirige a la petición.
* En caso contrario, clica en el ID de la petición en la que quieres añadir productos.
*   Una vez te encuentres en la siguiente pantalla, clica en Añadir productos.

    * _<mark style="background-color:$warning;">(Solo podemos añadir productos que previamente hayamos marcado “Tiene Stock”, véase artículo: CONFIGURACIÓN: Ventas/ Productos – Control Stock)</mark>_

    <figure><img src="../.gitbook/assets/image (4).png" alt=""><figcaption></figcaption></figure>


* Esta acción redirige a una ventana donde se alojan los productos que hayamos marcado con Stock.
* Selecciona los productos que quieras añadir a la petición.
* Clica Seleccionar, situado en la esquina superior izquierda, para guardar la selección.
* Una vez añadidos los productos, se actualiza la pantalla, mostrando el stock actual de cada artículo.
*   Localiza la columna Cantidad Solicitada y escribe el nº de artículos que quieres solicitar de cada producto.<br>

    <figure><img src="../.gitbook/assets/image (5).png" alt=""><figcaption></figcaption></figure>
* Una vez hecho esto, puedes exportar este listado a Excel, si fuera necesario, y mandarlo a tu proveedor, clicando en :arrow\_down:.
{% endstep %}

{% step %}
### Añadir stock

* Dentro del módulo de Almacén, donde se hayan todas las peticiones de stock, clica en el id de la petición de stock creada.
*   Accede al bloque de **Entradas**.

    <figure><img src="../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>
*   Dirígete a la columna **Añadir Cantidad Entregada**.<br>

    <figure><img src="../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
* Escribe la cantidad de artículos recibidos y clica en enter.
{% endstep %}
{% endstepper %}

Una vez introducidas las cantidades entregadas, el sistema actualizará automáticamente el inventario de cada producto, reflejando el nuevo stock disponible en tiempo real.\
Podrás consultar o modificar la petición en cualquier momento desde el módulo de almacén si fuese necesario.
