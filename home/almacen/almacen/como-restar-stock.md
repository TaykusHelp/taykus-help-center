# Cómo restar Stock

En este módulo puedes restar productos del inventario de forma fácil. Se hace desde **Entrada manual**: eliges el producto e indicas en negativo cuántas unidades quieres descontar.

Esto ayuda a mantener el stock actualizado y evita errores en el inventario.

Para ello, solo hay que seguir estos sencillos pasos:

{% stepper %}
{% step %}
### Acceso a Entrada manual

* Dirígete a la columna de la izquierda y selecciona **Almacén**.
* En el desplegable, clica en **Entrada Manual**.
{% endstep %}

{% step %}
### Restar la cantidad

* Selecciona, en la esquina superior izquierda, **Añadir Entrada**.
*   Se abrirá el siguiente formulario que deberás completar de la siguiente manera:<br>

    <div align="left"><figure><img src="../.gitbook/assets/restar-stock-cantidad.png" alt=""><figcaption></figcaption></figure></div>

    * **Ctd:** Es la cantidad que queremos restar en **NEGATIVO**, añadiendo el símbolo menos delante.
    * **Buscar Producto:** Al seleccionar, se abre un listado de todos los productos que tienen control de Stock.
* Clica en Añadir para guardar los cambios.
{% endstep %}
{% endstepper %}

Tras registrar la entrada manual, el sistema actualizará el stock del producto de forma inmediata.\
Este ajuste quedará reflejado en el inventario y podrá consultarse o corregirse posteriormente si fuese necesario.
