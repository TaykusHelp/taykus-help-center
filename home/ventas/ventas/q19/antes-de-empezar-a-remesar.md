# Antes de empezar a remesar

Antes de realizar un Q19, es importante tener en cuenta una serie de configuraciones y comprobaciones previas dentro del programa.\
Estos pasos te permitirán asegurarte de que los datos fiscales estén correctamente preparados para poder generar el modelo de forma adecuada.

{% stepper %}
{% step %}
### Acceso a Configuración de empresas

* Dirígete al menú de configuración situado en la esquina superior derecha.
* Clica en **Ventas**.
*   Selecciona la pestaña **Empresas.**<br>

    <figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear datos de empresa

*   Clica en ➕<br>

    <figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>

    <figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure>
* Completamos con los datos fiscales de la empresa. El único campo obligatorio es el mail
  * **NOTA IMPORTANTE:** no tocar el Invoice Number Format.
* Completar el apartado de domiciliaciones con el IBAN de la cuenta, el CIF/ VAT y el prefijo de emisor bancario y prefijo banco acreedor.
  * <mark style="background-color:$warning;">**NOTA IMPORTANTE:**</mark> <mark style="background-color:$warning;"></mark><mark style="background-color:$warning;">el prefijo de emisor bancario y prefijo banco acreedor, son dos datos que aporta el banco, también llamado sufijo y suele ser un número de 3 cifras, generalmente 000 ó 001.</mark>
* Clica guardar para terminar.
{% endstep %}
{% endstepper %}

Una vez completada esta configuración, la empresa quedará correctamente preparada a nivel fiscal para poder generar el modelo Q19 dentro del programa.

Recuerda revisar especialmente que los datos bancarios y fiscales estén bien informados y que no se modifique el campo **Invoice Number Format**, ya que esto podría afectar al correcto funcionamiento del proceso.

Con estas comprobaciones previas realizadas, ya podrás continuar con la generación del Q19 con mayor seguridad.
