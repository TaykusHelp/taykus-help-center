# Deudas

En **Ventas › Deudas** aparece todo lo que los clientes tienen pendiente de pagar y cuya fecha de vencimiento ya ha pasado, sea cual sea el tipo de venta (reservas, partidos, etc.). Las ventas con fecha futura no se consideran deuda y no salen aquí.

La pantalla tiene dos pestañas:

* **Pendiente de Pago:** las deudas que el club tiene que cobrar.
* **Pendiente Domiciliación:** las deudas que se cobrarán por domiciliación bancaria y que aún están pendientes de incluir en una remesa. Consulta [Deudas pendientes de domiciliación](deudas-pendientes-de-domiciliacion.md).

En las dos puedes filtrar por cualquier columna y descargar el listado con el botón de descarga.

Desde esta pantalla puedes:

* [Cobrar una deuda](como-cobrar-una-deuda.md) abriéndola en el TPV.
* [Enviar un email de deudas](como-enviar-un-email-de-deudas.md) a los clientes.
* [Anular una deuda](como-anular-una-deuda.md).

Los artículos explican la pestaña **Pendiente de Pago**. En **Pendiente Domiciliación** se hace igual.
