# Cómo emitir una factura desde Ventas > Líneas

Uno de los apartados más utilizados dentro del programa será la gestión de ventas y su posterior facturación. Para ello, será necesario conocer cómo localizar una venta ya registrada, acceder a su detalle y emitir una factura con los datos fiscales correspondientes.

En el siguiente video se muestra como realizar esre proceso:

### Video Explicativo

{% embed url="https://youtu.be/dW3OHLSIm6s" %}

En este artículo detallaremos cómo emitir una factura desde Ventas > Líneas y los pasos a seguir:

### Antes de empezar

Antes de emitir la factura, revisa que estén creados estos datos en:

* **Configuración > Ventas > Empresas**
* **Configuración > Ventas > Empresas clientes**

Para saber como hacerlo puedes consultar los siguientes artículos:

* [Cómo configurar los datos de empresa](https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/empresas/como-configurar-los-datos-de-empresa "mention")
* [Cómo crear empresas cliente en el sistema](https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/empresas-clientes/como-crear-empresas-cliente-en-el-sistema "mention")

{% stepper %}
{% step %}
### Acceso a Ventas - Líneas

* En el menú lateral, accede a **Ventas**.
* Haz clic en **Líneas**.
*   Busca la línea de venta desde la que quieras emitir la factura.<br>

    <figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Cómo emitir la factura

* Una vez localizada la línea, haz clic sobre el **ID**.
*   Dentro de la venta, pulsa el botón **Emitir factura**.<br>

    <figure><img src="../../.gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
* Se abrirá una ventana con los datos de facturación.
{% endstep %}

{% step %}
### Completar los datos de la factura

En el bloque **Emisor**:

* Selecciona la **empresa emisora** en el campo **Empresa**.
* El sistema rellenará automáticamente los datos asociados, como:
  * Nombre
  * CIF
  * Email
  * Teléfono

<figure><img src="../../.gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>

En el bloque **Cliente**, puedes elegir entre dos opciones:

**Persona física**

Si la factura es para un particular:

* Deja marcada la opción **Persona física**.
* Revisa o completa los datos del cliente:
  * Nombre completo
  * DNI
  * Email
  * Teléfono
  * Dirección

<figure><img src="../../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure>

**Empresa**

Si la factura es para una empresa:

* Marca la opción **Empresa**.
* En el campo **Empresa cliente**, selecciona la empresa correspondiente.
* El sistema completará automáticamente los datos fiscales de esa empresa.

<figure><img src="../../.gitbook/assets/image (10).png" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
### Guardar la factura

* Cuando todos los datos estén revisados, pulsa el icono de **guardar**.
* El sistema generará la factura asociada a esa venta.
{% endstep %}
{% endstepper %}

Una vez completados todos los pasos anteriores y revisados los datos de facturación, la factura se emitirá correctamente en el sistema. Recuerda comprobar siempre que tanto los datos del emisor como los del cliente sean correctos antes de guardarla, para evitar errores en la facturación.
