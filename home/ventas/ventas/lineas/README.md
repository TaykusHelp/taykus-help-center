# Líneas

En **Ventas › Líneas** tienes el listado de todo lo que genera el club, esté pagado o no: reservas, cuotas, productos, recargas de bonos… Cada venta aparece como una línea.

<figure><img src="../../.gitbook/assets/lineas-listado.png" alt=""><figcaption></figcaption></figure>

Puedes filtrar por cualquier columna y descargar el listado con el botón de descarga. Desde esta pantalla puedes:

* [Cobrar una venta](como-cobrar-una-venta-desde-lineas.md) abriéndola en el TPV.
* [Anular una venta](como-anular-una-venta-desde-lineas.md).
* [Anular una recarga de bono](como-anular-una-recarga-de-bono.md).
* Emitir una factura clicando en el **Id** de la línea. Consulta [Cómo emitir una factura desde Ventas > Líneas](../facturas/como-emitir-una-factura-desde-ventas-greater-than-lineas.md).

Cuando se anula una venta, en el listado aparecen dos líneas marcadas en color: en rosa claro, la devolución (con el importe en negativo), y en rosa más oscuro, la venta anulada.

> **Importante:** para cobrar o anular necesitas tener una caja abierta. Consulta [Cómo abrir la caja](../cajas/como-abrir-la-caja.md).
