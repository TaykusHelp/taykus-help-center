# Cómo anular una recarga de bono

Si se realiza una recarga de bono por error, puedes anular la operación para dejar sin efecto tanto el cobro como el saldo añadido al cliente.

La anulación de una recarga funciona como la anulación de una compra: corrige la venta registrada y elimina del bono el saldo, importe o sesiones que se habían cargado previamente.

En este artículo te explicamos cómo anular correctamente una recarga de bono.

> **Nota importante:** Solo es posible anular una recarga de bono si el saldo añadido permanece completo.
>
> Si el cliente ha utilizado parte del saldo, sesiones o importe cargado, no se podrá realizar la devolución de esa recarga, ya que el sistema no podrá retirar la totalidad del saldo añadido originalmente.

{% stepper %}
{% step %}
### Acceso a ventas

* Dirígete a la columna de la izquierda y selecciona **Ventas**.
* Se abre un desplegable. Selecciona **Líneas**.

<div align="left"><figure><img src="../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Localiza la línea de venta

* En el listado de líneas de venta, localiza el cobro correspondiente a la recarga que quieres anular.
* Selecciona la línea.
* A continuación, clica sobre **anular**.
*   Elige la opción **Anular deudas y devolver pagos.**<br>

    <figure><img src="../../.gitbook/assets/image (30).png" alt=""><figcaption></figcaption></figure>


* Antes de confirmar, el sistema mostrará un aviso de verificación.\
  ![](<../../.gitbook/assets/image (31).png>)
* Pulsa **OK** para completar la anulación.
{% endstep %}

{% step %}
### Comprobación

*   Tras anular la venta, puedes verificar que el proceso se ha realizado correctamente comprobando que se ha generado el movimiento negativo correspondiente en las líneas de venta.<br>

    <figure><img src="../../.gitbook/assets/image (32).png" alt=""><figcaption></figcaption></figure>


* También puedes comprobarlo accediendo al saldo del jugador, donde el saldo añadido por la recarga ya no debería aparecer disponible.
{% endstep %}
{% endstepper %}

Una vez anulada la recarga, el sistema dejará sin efecto la compra y retirará el saldo añadido al bono del cliente.

Recuerda revisar previamente que el saldo cargado sigue completo, ya que si se ha utilizado parte de la recarga no será posible realizar la devolución. Así evitarás descuadres entre el cobro registrado y el saldo disponible del jugador.
