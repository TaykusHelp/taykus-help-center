# Cuotas

En **Ventas › Cuotas** gestionas las cuotas: cobros que se repiten con una periodicidad, por ejemplo la mensualidad de un grupo de academia. Hasta que una cuota se emite, puedes cambiar su precio, su día de vencimiento u omitirla.

Antes de nada, la cuota tiene que estar creada como producto. Consulta [Cómo crear un producto tipo Cuota](../../../configuracion/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota.md).

Desde esta sección puedes:

* [Ver las cuotas](como-ver-las-cuotas.md) por cuota, por jugador o desde un grupo de academia.
* [Emitir una cuota](como-emitir-una-cuota.md) para que quede pendiente de pago.
* [Pagar una cuota](como-pagar-una-cuota.md) desde el calendario de cuotas.
* [Restablecer una cuota](como-restablecer-una-cuota.md) si la has emitido por error.
* [Omitir una cuota](como-omitir-una-cuota.md) para que ese recibo no se cobre.
* [Modificar el precio de una cuota](como-modificar-el-precio-de-una-cuota.md).
* [Cambiar el día de vencimiento de una cuota](como-cambiar-el-dia-de-vencimiento-de-una-cuota.md).
* [Activar el cobro automático con tarjeta](como-activar-el-cobro-automatico-con-tarjeta.md).
* [Automatizar la emisión de cuotas](como-automatizar-la-emision-de-cuotas.md).
* [Automatizar la cancelación por impago](como-automatizar-la-cancelacion-por-impago.md).
* [Dar de baja a un cliente de una cuota](como-dar-de-baja-a-un-cliente-de-una-cuota.md).

Si la cuota cambia el tipo de cliente (por ejemplo, de No socio a Socio), es una membresía. Consulta [Qué es una membresía y cómo funciona](que-es-una-membresia-y-como-funciona.md).
