{% tab title="Estudiantes" %}
## Cómo añadir alumnos

Añadir alumnos es el paso en el que cada jugador queda inscrito oficialmente en un curso de academia. Aquí se decide quién forma parte del grupo y el sistema los vincula a sus entrenamientos y al tipo de inscripción que les corresponda. Es el proceso que convierte la configuración del curso en un grupo real, con sus participantes ya registrados y listos para empezar.

Si se va a usar **precios por día**, es imprescindible crearlos **antes** de añadir los alumnos. Solo así el sistema asignará correctamente qué días puede elegir cada alumno y qué precio corresponde. Una vez hecho, ya se puede configurar los alumnos y dejar el grupo listo para funcionar.

* _Para crear precios por días, véase el siguiente artículo:_\
  <a href="academia/grupos-de-academia/precios-por-dias.md" class="button primary" data-icon="medal">Precios por día</a>

Para que los alumnos queden bien asignados al grupo, es necesario que los entrenamientos estén creados de antemano. Si se sigue ese orden, el sistema podrá vincularlos correctamente a sus sesiones y el curso quedará organizado desde el principio.

* _Para crear los entrenamientos, véase el siguiente artículo:_\
  <a href="academia/grupos-de-academia/como-crear-los-entrenamientos.md" class="button primary" data-icon="medal">Cómo crear los entrenamientos</a>

Para añadir alumnos hay que seguir estos pasos:

{% stepper %}
{% step %}
### Acceso al módulo de Academia

* Dirígete al menú lateral izquierdo y selecciona Academia.
{% endstep %}

{% step %}
### Acceso a los alumnos del grupo escuela

* Si no se tiene el grupo previamente creado visita el siguiente enlace para saber como crearlo:\
  <a href="academia/grupos-de-academia/como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">Cómo crear un grupo de academia</a>
* Si se tiene el grupo previamente creado, clica sobre el id para acceder a el.
*   Dirígete a la sección de **Estudiantes**.

    <figure><img src=".gitbook/assets/image (7).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Añadir alumnos

* Clica en :heavy\_plus\_sign:
*   Se abre el siguiente panel que se deberá cumplimentar de esta manera:<br>

    <figure><img src=".gitbook/assets/image (8).png" alt=""><figcaption></figcaption></figure>

    * **Cliente:** Busca el nombre del alumno o alumnos a los que se quiera añadir. Si coinciden en días, se puede añadir más de uno a la vez.
    * **Inicio:** Selecciona la fecha en la que el alumno o alumnos iniciarán el curso.
    * **Fin:** Selecciona la fecha en la que el alumno/s terminan el curso. Esta fecha podrá modificarse más adelante en el caso de que el alumno solicite la baja antes de que finalice el curso.
    * **Observaciones&#x20;**_**(Opcional)**_**:** Espacio para escribir algún detalle o dejar constancia de algo.
    * **Días:** Hacemos check en el día o los días que vaya a asistir el alumno al curso. Con esto, se añaden a la reserva de manera automática los días de asistencia de cada alumno.
* Clica en Guardar, para dejar a los alumnos añadidos al grupo escuela.
{% endstep %}
{% endstepper %}

{% tab title="Entrenamientos" %}
## Cómo crear los entrenamientos

Los **entrenamientos** son las sesiones semanales del curso: día, hora y pista, también es posible selección de profesor, en la que entrena cada grupo. Al crearlos, se puede **relacionar las reservas con el grupo de academia**, lo que hace que todas las asistencias y plazas queden vinculadas al curso y no como reservas sueltas.

Si se va a usar **precios por día**, es imprescindible crearlos **antes** de añadir los entrenamientos. Solo así el sistema asignará correctamente qué días puede elegir cada alumno y qué precio corresponde. Una vez hecho, ya puedes configurar los entrenamientos y dejar el grupo listo para funcionar.

* _Para crear precios por días, véase el siguiente artículo:_\
  <a href="academia/grupos-de-academia/precios-por-dias.md" class="button primary" data-icon="medal">Precios por día</a>

Para crear los entrenamientos se ha de seguir estos sencillos pasos:

{% stepper %}
{% step %}
### Acceso al módulo de Academia

* Dirígete al menú lateral izquierdo y selecciona Academia.
{% endstep %}

{% step %}
### Acceso a los entrenamientos del grupo escuela

* Si no se tiene el grupo previamente creado visita el siguiente enlace para saber como crearlo:\
  <a href="academia/grupos-de-academia/como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">Cómo crear un grupo de academia</a>
* Si se tiene el grupo previamente creado, clica sobre el id para acceder a el.
*   Dirígete a la sección de **Entrenamientos**.

    <figure><img src=".gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear entrenamientos

*   Clica en Calendario.

    <figure><img src=".gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>
* Se abre el Calendario del club pero dentro del módulo de Academia.
* Realizamos una **reserva múltiple** como siempre, pero es importante hacerlo **desde el módulo de Academia**. Solo así la reserva quedará vinculada al grupo y, cuando se añadan a los alumnos, el sistema los llevará automáticamente a sus entrenamientos correspondientes. Todo queda ordenado y dentro del mismo curso.
  * _Para realizar una reserva múltiple, véase el siguiente artículo:_\
    <a href="https://app.gitbook.com/s/hSQoRJmdDmzxYVh7vpFW/calendario/reservar-multiples/como-crear-una-reserva-multiple" class="button primary" data-icon="clock">Cómo crear una reserva múltiple</a>
* Una vez creada la reserva múltiple, los entrenamientos quedan asignados automáticamente a ese grupo. A partir de ahí, todo el curso funciona ya bajo esa configuración.
{% endstep %}
{% endstepper %}

{% tab title="Precios por días" %}
## Precios por días

Los **precios por días** permiten que, dentro de un mismo curso, cada jugador elija cuántos días quiere asistir a la semana. Si el grupo entrena de lunes a viernes, el alumno puede apuntarse solo un día, dos, tres… o los cinco. Es flexible para el jugador y práctico para el club, porque ajusta el precio según la asistencia real de cada uno.

Es importante seguir un orden al crear el grupo. Si se va a usar **precios por días**, deben añadirse primero, antes de crear los entrenamientos y antes de añadir jugadores. Esto evita errores, asegura que cada alumno vea el precio correcto según los días que elija y mantiene toda la configuración del curso coherente desde el principio.

Para crear los precios por día hay que seguir estos pasos:

{% stepper %}
{% step %}
### Acceso al módulo de Academia

* Dirígete al menú lateral izquierdo y selecciona Academia.
{% endstep %}

{% step %}
### Acceso a los precios por días del grupo escuela

* Si no se tiene el grupo previamente creado visita el siguiente enlace para saber como crearlo:\
  <a href="https://taykus-help-center.gitbook.io/taykushelpcenter/home/academia/academia/grupos-de-academia/como-crear-un-grupo-de-academia" class="button primary">Cómo crear un grupo de Academia</a>
* Si se tiene el grupo previamente creado, clica sobre el id para acceder a el.
*   Dirígete a la sección de **Precios por días**.

    <figure><img src=".gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
### Crear precios por días

* Clica en ➕.
*   Se abre el siguiente panel, que se deberá cumplimentar de esta forma:

    ![](https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F366262635-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252F7f6wmhmmi292HcDQR5ok%252Fuploads%252F0pLcQloUHeEoqmNQ0MRi%252Fimage.png%3Falt%3Dmedia%26token%3D28e183a9-e93d-4bcc-8670-551030ea79d4\&width=768\&dpr=3\&quality=100\&sign=e5cff816\&sv=2)

    * **Número de días:** Indicamos el número de días al que se le va a poner un precio.
    * **Producto:** Establece el precio de este número de días. El producto debe ser de categoría **Cuota**.
      * _Para crear productos de Tipo Cuota, véase el siguiente artículo:_<a href="https://taykus-help-center.gitbook.io/taykushelpcenter/configuracion/configuracion/ventas/como-crear-un-producto-tipo-cuota" class="button primary">Cómo crear un producto tipo Cuota</a>
    * Clica en Guardar.
{% endstep %}
{% endstepper %}

Hay que crear un producto por cada opción que se quiera ofrecer. Si se permite venir uno, dos, tres o cuatro días, se tendrá que crear el producto de 1 día, el de 2 días, el de 3 días y el de 4 días, cada uno con su precio correspondiente. Así el alumno puede elegir exactamente cuántos días quiere asistir.
{% endtab %}

{% tab title="Cuotas" %}
## Cuotas

La sección de **Cuotas** te permite tener un control visual y ordenado de todo lo relacionado con los pagos de tu grupo de academia. Desde aquí puedes ver qué cuotas están emitidas, quién ha pagado, quién sigue pendiente y si se ha realizado alguna modificación en sus importes. Es la forma más rápida de revisar el estado económico del grupo sin perderte entre comprobaciones manuales.

Para acceder y trabajar se debe seguir estos pasos:

{% stepper %}
{% step %}
### Acceso al módulo de Academia

* Dirígete al menú lateral izquierdo y selecciona Academia.
{% endstep %}

{% step %}
### Acceso a las cuotas del grupo de academia

* Clica sobre el id del grupo deseado.
*   Dirígete a la sección de **Cuotas.**<br>

    <figure><img src=".gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure>
* En esta sección se visualizarán todos los tipos de cuota habilitados en este grupo.
  * Si solo se tiene uno disponible se verá en un único listado, si tenemos la opción de _Precios por días_ activada, se dividirán como en la imagen.
{% endstep %}
{% endstepper %}

Para aprender a gestionar las cuotas, visita el siguiente enlace

<a href="https://app.gitbook.com/s/QFNRYl4MHLCMNIVqCXJJ/ventas/cuotas" class="button primary" data-icon="credit-card">Cuotas</a>
