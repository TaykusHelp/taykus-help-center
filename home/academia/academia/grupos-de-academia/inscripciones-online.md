# Inscripciones Online

Las inscripciones online permiten que el alumno se apunte al curso de academia de forma rápida y segura. Evitan papeleo, reducen errores y actualizan las plazas en tiempo real. El club gana organización; el alumno, comodidad. Simplifica todo el proceso de alta en un solo paso.

Para poder habilitarlas solo hay que seguir estos sencillos pasos:

{% stepper %}
{% step %}
### Acceso al modulo de Academia:

* Dirígete al menú lateral izquierdo y selecciona Academia.
{% endstep %}

{% step %}
### Editar o crear grupo de Academia

* Si no se tiene el grupo previamente creado visita el siguiente enlace para saber como crearlo:\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">Cómo crear un grupo de academia</a>
* Si se tiene el grupo previamente creado, clica sobre el id para acceder a el.
*   Una vez dentro, clica sobre <i class="fa-pen" style="color:purple;">:pen:</i> para editar.<br>

    <figure><img src="../../.gitbook/assets/image (11).png" alt=""><figcaption></figcaption></figure>


{% endstep %}

{% step %}
### Habilitar las inscripciones online

* Baja con el ratón o scroll hasta el apartado de **Inscripciones**.
*   Para habilitar las inscripciones debemos de completar este apartado de la siguiente manera:<br>

    <figure><img src="../../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

    * **Mostrar Online:** Este check solo hace que el curso se vea en la web. Nada más. No activa inscripciones ni cambia su gestión.&#x20;
    * **Días de anticipación para mostrar online:** Marcan cuántos días antes quieres que el curso aparezca visible online. Solo controlan la **fecha de visibilidad.**
    * **Permitir inscripción online:** Activa que los alumnos puedan apuntarse al curso desde la web. Sin esto marcado, el curso solo se muestra, pero no admite inscripciones.
    * **Fecha de inicio de inscripciones:** Fecha a partir de la cual, el alumno puede hacer la inscripción al curso.
    * **Fecha de Fin de inscripciones:** Fecha límite hasta la que el alumno puede inscribirse.
{% endstep %}

{% step %}
### Guardar

* Clica en Guardar, para salvar los cambios.
{% endstep %}
{% endstepper %}
