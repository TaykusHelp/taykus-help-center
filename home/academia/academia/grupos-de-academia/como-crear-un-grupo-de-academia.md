# Cómo crear un grupo de Academia

En este artículo, te explicamos paso a paso cómo crear grupos de escuela dentro de nuestro programa de gestión deportiva. Gracias a un proceso intuitivo y eficiente, podrás organizar a los participantes de forma óptima, siguiendo criterios específicos que mejoran la experiencia de los usuarios y facilitan la gestión de actividades.

A la hora de crear un grupo de academia, cabe destacar la importancia de seguir un orden en el paso a paso.

{% stepper %}
{% step %}
### Acceso al módulo de Academia:

* Dirígete al menú lateral izquierdo y selecciona Academia.
* Se abrirá la sección donde se gestionan todos los grupos de escuela creados a partir de ahora.
{% endstep %}

{% step %}
### Creación del nuevo grupo de Academia

* Haz clic en :heavy\_plus\_sign: para crear un nuevo grupo.
*   Se abrirá un formulario que se debe cumplimentar de la siguiente manera:<br>

    <figure><img src="../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>



    *   **DATOS GENERALES:**

        * **Nombre:** Especifica el nombre del grupo. Te recomendamos seguir una estructura clara como:\
          `Nombre del grupo – Categoría (edad o nivel) – Días – Horario`.
        * **Logo:** Si la escuela tiene un logo, puedes añadirlo aquí.
        * **Temporada:** Indica el periodo de duración del curso.
        * **Fin:** Fecha de finalización del curso/escuela/academia.
        * **Detalles:** Espacio para añadir una descripción adicional.
        * **Producto:** Selecciona un producto, **de categoría: COUTA,** previamente creado. Este es el precio que se le asignará a este curso.
          * _Para crear productos tipo Cuota, véase el siguiente artículo:_ \
            <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-cuota" class="button primary" data-icon="box">Cómo crear un producto tipo Cuota</a>
        * **Máximos Participantes:** Define el número máximo de personas que podrán integrarlo.
        * **Nivel Mínimo:** Establezca el nivel mínimo requerido para este grupo.
        * **Nivel Máximo:** Establezca el nivel máximo requerido para este grupo.

        _<mark style="background-color:yellow;">(Con estos datos ya podríamos dejar creado nuestro grupo de academia)</mark>_
    * Clica en Guardar para salvar los cambios.


{% endstep %}
{% endstepper %}

A la hora de crear un Grupo de Academia, también se tiene la posibilidad de seleccionar si se quiere que las Inscripciones sean Online u ofertar una clase abierta/suelta, como por ejemplo si nos falta un alumno, a través de nuestro espacio web.&#x20;
