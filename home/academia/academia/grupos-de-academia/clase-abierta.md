# Clase abierta

Ofertar una clase abierta sirve para llenar huecos en un grupo cuando falta un alumno. El club completa la clase, y los usuarios pueden apuntarse desde la web de forma rápida. Ayuda a no perder horas de pista ni ingresos y mantiene los grupos siempre activos.

Solo hay que seguir estos sencillos pasos:

{% stepper %}
{% step %}
### Acceso al módulo de Academia

* Dirígete al menú lateral izquierdo y selecciona Academia.
{% endstep %}

{% step %}
### Editar o Crear Grupo

* Si no se tiene el grupo previamente creado visita el siguiente enlace para saber como crearlo:\
  <a href="como-crear-un-grupo-de-academia.md" class="button primary" data-icon="medal">Cómo crear un grupo de academia</a>
* Si se tiene el grupo previamente creado, clica sobre el id para acceder a el.
*   Una vez dentro, clica sobre <i class="fa-pen" style="color:purple;">:pen:</i> para editar.<br>

    <figure><img src="../../.gitbook/assets/image (13).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Activar clase abierta

* Baja con el ratón o scroll hasta el apartado de **Clase abierta**.
*   Para activar la oferta de clases sueltas online se debe completar este apartado de la siguiente manera:<br>

    <figure><img src="../../.gitbook/assets/image (14).png" alt=""><figcaption></figcaption></figure>

    * **Producto de clase Abierta:** Establece el precio de una reserva de clase abierta. El producto debe ser de categoría **Servicio**.
      * _Para crear Productos tipo Servicio, véase el siguiente articulo:_\
        <a href="https://app.gitbook.com/s/V0h7jTfpeuZY1RmPEtNK/configuracion/ventas/productos/como-crear-un-producto-tipo-servicio" class="button primary" data-icon="box">Cómo crear un producto de tipo servicio</a>
    * **Permitir inscripción online de clase abierta:**  Activa que los jugadores puedan apuntarse a la clase ofertada desde la web.
    * **Días de anticipación para inscripción online de clase abierta:** Marcan cuántos días antes se quiere que la clase ofertada aparezca online y permita su inscripción.
{% endstep %}

{% step %}
### Guardar

* Clica en guardar, para salvar los cambios.


{% endstep %}
{% endstepper %}
