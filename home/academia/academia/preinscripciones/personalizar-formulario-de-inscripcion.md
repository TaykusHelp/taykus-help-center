# Personalizar formulario de inscripción

La sección **Personalizar Registro** permite configurar los campos que deberán completar los alumnos cuando realizan una **preinscripción en la escuela o academia**.

Esto permite al club recopilar información adicional sobre los alumnos antes de asignarlos a un grupo o nivel.

{% stepper %}
{% step %}
### Acceder a la sección Personalizar Registro

* Dirígete al menú de la izquierda y clica sobre **Academia**.
* En el desplegable, selecciona **Preinscripciones**.
* Selecciona la **preinscripción** que deseas gestionar.
* En la parte superior, haz clic en la pestaña **Personalizar Registro**.

![](<../../.gitbook/assets/image (3)>)
{% endstep %}

{% step %}
### Añadir campos al formulario

En la parte superior encontrarás diferentes **campos predefinidos** que puedes utilizar en el formulario.

Para añadir uno de estos campos:

* Selecciona el campo que deseas utilizar.
* **Arrástralo hacia la parte inferior del formulario.**
* Suéltalo en la **Columna Izquierda** o **Columna Derecha** según cómo quieras organizar el formulario.

Esto permite estructurar el formulario en **una o dos columnas**, facilitando su lectura para los usuarios.

![](<../../.gitbook/assets/image (4)>)
{% endstep %}

{% step %}
### Definir si un campo es obligatorio

Una vez que el campo se ha añadido al formulario, aparecerá un **check junto a él**.

* Si activas este check, el campo se convertirá en **obligatorio**, por lo que el usuario deberá completarlo para poder finalizar la inscripción.
* Si el check no está marcado, el campo será **opcional**.

![](<../../.gitbook/assets/image (5)>)
{% endstep %}

{% step %}
### Crear nuevos campos personalizados

Además de los campos predefinidos, también es posible crear campos nuevos.

Para ello:

* Clica en **Añadir Nuevo**.
* Se abrirá la ventana **Añadir Campo Dinámico**.

Deberás completar los siguientes campos:

**Etiqueta:** Nombre del campo que verá el usuario en el formulario.\
**Tipo de campo:** Define el tipo de respuesta que podrá introducir el usuario.

Entre las opciones disponibles se encuentran:

![](<../../.gitbook/assets/image (6)>)

* Texto
* Si/No
* Lista
* Número
* Área de texto
* Fecha
* Email
* Carga de archivo
* Selección múltiple

Opcionalmente también puedes configurar:

* **Opciones:** Valores disponibles cuando el campo sea de tipo lista o selección.
* **Valor por defecto:** Valor que aparecerá previamente seleccionado en el formulario.

Una vez configurado el campo, clica en **Guardar** para añadirlo al formulario.

Una vez configurados los campos del formulario, los usuarios deberán completar esta información durante el proceso de inscripción. Todos los datos recogidos quedarán asociados a cada participante y podrán consultarse posteriormente desde la sección **Participantes**.
{% endstep %}
{% endstepper %}

Personalizando el formulario de preinscripción, el club puede recopilar información adicional de los alumnos y organizar mejor las solicitudes antes de asignarlos a los distintos grupos de la escuela.
