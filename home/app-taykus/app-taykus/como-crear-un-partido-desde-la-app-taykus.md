# Cómo crear un partido desde la app Taykus

Además de realizar reservas, la app Taykus permite a los jugadores crear partidos para que otros usuarios puedan apuntarse y completar el grupo de juego.

Esta opción resulta útil cuando el jugador quiere organizar un partido, pero aún no tiene todos los participantes confirmados. Desde la app podrá seleccionar el club, la fecha, la hora y la pista disponible, así como configurar los datos necesarios para publicar el partido.
