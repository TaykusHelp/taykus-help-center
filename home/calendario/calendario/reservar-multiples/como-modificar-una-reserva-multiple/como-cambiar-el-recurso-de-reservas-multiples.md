# Cómo cambiar el recurso de reservas múltiples

Puedes pasar muchas reservas de una pista a otra a la vez, por ejemplo por mantenimiento o por una reorganización del club. El cambio se puede aplicar a toda la reserva múltiple o solo a unas fechas.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a la reserva múltiple

* Dirígete al menú lateral izquierdo y selecciona **Calendario**.
*   Clica sobre **Reservas Múltiples**.<br>

    <figure><img src="../../../.gitbook/assets/image (112).png" alt=""><figcaption></figcaption></figure>
* Localiza la reserva múltiple que quieres modificar y clica sobre su **ID**.
* Verás el listado de todas las reservas que forman parte de ella.

<figure><img src="../../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Selección de las reservas

* **Para cambiar todas las reservas:** clica sobre **ID** en la cabecera para seleccionarlas todas.
* **Para cambiar solo una fecha o un periodo:** filtra antes por la columna **Inicio**:
  * Clica sobre las tres líneas horizontales de la columna.
  *   Elige **Mayor que** para cambiar las reservas a partir de una fecha.

      <figure><img src="../../../.gitbook/assets/image (114).png" alt=""><figcaption></figcaption></figure>
  * O elige **En el rango** para cambiar las reservas entre dos fechas.
  * Después, selecciona las reservas filtradas.
{% endstep %}

{% step %}
### Cambiar el recurso

* Con las reservas seleccionadas, clica en **Acciones**.
*   Selecciona **Cambiar recursos**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (115).png" alt=""><figcaption></figcaption></figure></div>
*   En la ventana que se abre, elige la pista o el recurso al que quieres pasar las reservas.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (118).png" alt=""><figcaption></figcaption></figure></div>
* Clica en **OK**.
{% endstep %}
{% endstepper %}

El sistema comprobará la disponibilidad antes de aplicar los cambios. Si alguna reserva no se puede modificar porque el nuevo recurso no está libre en ese horario, aparecerá una ventana con los errores:

<div align="left"><figure><img src="../../../.gitbook/assets/image (117).png" alt=""><figcaption></figcaption></figure></div>

En ese caso puedes:

* Guardar los cambios válidos.
* Descartar las reservas con error.

Una vez confirmado, el recurso quedará actualizado en las reservas seleccionadas.
