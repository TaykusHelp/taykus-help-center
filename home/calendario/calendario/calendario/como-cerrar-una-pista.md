# Cómo cerrar una pista

Cerrar una pista permite bloquearla durante un día completo para que no se puedan hacer reservas en ella. Esta opción es especialmente útil en días festivos, eventos internos del club, mantenimiento o por cualquier otro motivo operativo.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Calendario

* Dirígete al menú lateral izquierdo y selecciona **Calendario**.
{% endstep %}

{% step %}
### Selección de fecha

* Selecciona el día que quieres cerrar.

<figure><img src="../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>

* Al clicar sobre el día, el calendario te llevará directamente a esa fecha.
{% endstep %}

{% step %}
### Cierre de la pista

* Clica sobre el nombre de la pista.
* Se abrirá el siguiente menú:

<div align="left"><figure><img src="../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure></div>

* Selecciona **Cerrar día entero**.
{% endstep %}
{% endstepper %}

> **Importante:** el cierre se aplica solo a la pista seleccionada. Si necesitas cerrar más pistas ese mismo día, repite el proceso con cada una de ellas.
