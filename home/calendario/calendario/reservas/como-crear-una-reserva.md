# Cómo crear una reserva

Uno de los principales usos que se dará al programa será la gestión de reservas. Para ello, será necesario aprender a crear reservas, identificar los diferentes tipos disponibles, realizar las reservas, añadir jugadores, procesar los pagos, entre otras funciones.

En este artículo detallaremos como crear una reserva y los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Calendario

* Dirígete al menú lateral izquierdo y selecciona **Calendario.**

<figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Creación de la reserva

* Clica sobre la pista y la hora a la que se quiere hacer la reserva.
* Se abrirá una nueva ventana donde se selecciona el tipo de reservaa.\
  ![](<../../.gitbook/assets/image (66).png>)
* Clica sobre el tipo de reserva deseada.
{% endstep %}

{% step %}
### Menú de reserva

* Se abre la ventana de la imagen que ha de cumplimentarse de la siguiente manera:

<figure><img src="../../.gitbook/assets/image (67).png" alt=""><figcaption></figcaption></figure>

* **Jugador:** no es un campo obligatorio pero desde aquí se puede hacer una búsqueda del jugador titular de la reserva.
* **Pista:** aunque se selecciona en el paso anterior, es posible equivocarse, en estos casos se puede modificar la pista desde aquí.
* **Duración:** previamente configurada, se podrá seleccionar a la derecha.
* **Observaciones y comentarios:** por si se necesita dejar algún apunte.
* **Enviar comunicaciones:** esta casilla está marcada por defecto, para informar al los participantes de cualquier cambio.
{% endstep %}

{% step %}
### Guardar la reserva

Existen tres opciones de guardado:

* **Guardar y Pagar:** que guardará la reserva y nos dirigirá directamente al TPV para dejarla abonada.
* **Guardar y Nuevo:** esta opción es para guardar la reserva que acabamos de crear y abrir de nuevo el menú para la selección del tipo de reserva y el menú como el que vemos en la imagen. La hora se escoge de manera automática y sería la siguiente disponible.
* **Guardar:** clicando sobre <i class="fa-floppy-disk" style="color:blue;">:floppy-disk:</i> guardará nuestra reserva y nos llevará al calendario para poder visualizarla.
{% endstep %}
{% endstepper %}

Una vez hecho esto podremos visualizar la reserva en el calendario.\
![](<../../.gitbook/assets/image (100).png>)
