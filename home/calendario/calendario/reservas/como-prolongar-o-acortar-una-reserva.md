# Cómo prolongar o acortar una reserva

Puedes cambiar la duración de una reserva directamente en el calendario, para alargar o reducir el tiempo de juego o para bloquear una pista más o menos tiempo.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Calendario

*   Dirígete al menú lateral izquierdo y selecciona **Calendario**.<br>

    <figure><img src="../../.gitbook/assets/image (21).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Cambiar la duración

* Clica sobre la reserva y sitúate en el borde de arriba (para cambiar la hora de inicio) o en el de abajo (para cambiar la hora de fin).
*   Aparecerá una doble flecha, como en la imagen. Mantén pulsado y arrastra hacia arriba o hacia abajo hasta la nueva duración.<br>

    <figure><img src="../../.gitbook/assets/image (22).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Confirmar el cambio

*   Al soltar, se abrirá una ventana de confirmación:

    <div align="left"><figure><img src="../../.gitbook/assets/image (23).png" alt=""><figcaption></figcaption></figure></div>

    * **Actualizar precio:** recomendado. Ajusta el importe a la nueva duración o franja horaria.
    * **Notificar participantes:** envía un email a los jugadores para avisarles del cambio.
* Pulsa **OK** para guardar los cambios.
{% endstep %}
{% endstepper %}

> **Importante:** revisa la nueva hora de inicio y de fin antes de confirmar para evitar solapes con otras reservas.
