# Cómo compartir una reserva

Puedes compartir cualquier reserva con los jugadores, por ejemplo por WhatsApp, para que tengan a mano toda la información y el enlace directo.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Abrir las opciones para compartir

* Clica sobre la reserva.
* Dirígete al menú de la derecha.
*   Verás dos formas de compartirla, según lo que necesites.

    <figure><img src="../../.gitbook/assets/image (107).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Opción 1: Compartir (mensaje listo para enviar)

Al clicar en **Compartir**, el sistema crea un mensaje con formato que incluye:

* Nombre del club
* Nivel del partido
* Fecha y duración
* Ubicación
* Estado de las plazas
* Enlace directo de inscripción

<div align="left"><figure><img src="../../.gitbook/assets/image (110).png" alt=""><figcaption></figcaption></figure></div>

Es la mejor opción para enviarlo por WhatsApp, porque muestra toda la información de forma clara.
{% endstep %}

{% step %}
### Opción 2: Copiar link

Al clicar en **Copiar link**, el sistema copia solo el enlace directo a la reserva.

Es útil si:

* Quieres escribir tu propio mensaje.
* Vas a incluirlo en una campaña o newsletter.
* Solo necesitas el enlace.
{% endstep %}
{% endstepper %}
