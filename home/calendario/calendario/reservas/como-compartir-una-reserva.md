# Cómo compartir una reserva

Una vez creada una reserva dentro del programa, es posible compartirla fácilmente con los jugadores para que puedan acceder a la información correspondiente.

Esta opción resulta útil, por ejemplo, cuando se quiere enviar la reserva por WhatsApp u otro medio, facilitando el acceso directo a sus datos.

En este artículo te mostramos dónde localizar esta opción y cómo compartir una reserva paso a paso.

{% stepper %}
{% step %}
### Compartir el enlace de la reserva

* Selecciona la reserva.
* Dirígete al menú de la derecha.
*   El sistema permite compartir una reserva de dos maneras distintas, según lo que necesites.

    <figure><img src="../../.gitbook/assets/image (107).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Opción 1: Compartir (mensaje automático con formato)

Al hacer clic en **Compartir**, el sistema genera automáticamente un mensaje listo para enviar, que incluye:

* Nombre del club
* Nivel del partido
* Fecha y duración
* Ubicación
* Estado de las plazas
* Enlace directo de inscripción

<div align="left"><figure><img src="../../.gitbook/assets/image (110).png" alt=""><figcaption></figcaption></figure></div>

Este formato es ideal para enviarlo directamente por WhatsApp, ya que muestra toda la información de la reserva de forma clara y visual.<br>
{% endstep %}

{% step %}
### Opción 2: Copiar link

Al hacer clic en **Copiar link**, el sistema copia únicamente el enlace directo a la reserva.

Esta opción es útil si:

* Quieres redactar tu propio mensaje
* Vas a integrarlo en una campaña o newsletter
* Solo necesitas el enlace
{% endstep %}
{% endstepper %}

Una vez compartida la reserva, los jugadores podrán acceder de forma más rápida y sencilla a la información correspondiente a través del enlace enviado.

Esta opción facilita la comunicación y agiliza la gestión de la reserva, especialmente cuando se necesita enviar el acceso por canales externos como WhatsApp u otras aplicaciones de mensajería.

Con estos pasos, ya podrás compartir cualquier reserva directamente desde el programa.
