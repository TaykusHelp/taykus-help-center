# Cómo mover una reserva

Puedes cambiar una reserva de pista, de hora o de día por un torneo, un evento, mantenimiento o porque los jugadores lo piden. Hay dos formas de hacerlo: arrastrándola o desde su menú.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Calendario

*   Dirígete al menú lateral izquierdo y selecciona **Calendario**.<br>

    <figure><img src="../../.gitbook/assets/image (17).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Opción 1: Mover la reserva arrastrando

* Clica sobre la reserva y mantén pulsado.
*   Arrástrala hasta la nueva pista o la nueva hora.<br>

    <figure><img src="../../.gitbook/assets/image (18).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Opción 2: Mover la reserva desde el menú

* Clica sobre la reserva.
*   En el menú que se abre a la derecha, selecciona :scissors: **Mover**.

    <div align="left"><figure><img src="../../.gitbook/assets/image (19).png" alt=""><figcaption></figcaption></figure></div>
* El menú se cerrará. Clica sobre la nueva fecha (si cambias de día), la nueva hora o la nueva pista.
*   Se abrirá una ventana de confirmación:<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (20).png" alt=""><figcaption></figcaption></figure></div>

    * **Actualizar precio:** recomendado. Ajusta el importe si la nueva franja tiene otro precio.
    * **Notificar participantes:** avisa a los jugadores del cambio.
* Pulsa **OK** para confirmar.
{% endstep %}
{% endstepper %}

> **Importante:** antes de confirmar, revisa la fecha, la pista y el precio para asegurarte de que el cambio es correcto.
