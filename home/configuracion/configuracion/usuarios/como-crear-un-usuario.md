# Cómo crear un usuario

Cada persona del club que vaya a usar Taykus necesita su propio usuario, con su email y contraseña. El rol del usuario decide qué puede ver y hacer en el programa.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Usuarios

* Clica en el icono <i class="fa-gear" style="color:blue;">:gear:</i> de la esquina superior derecha y entra en **Configuración**.
*   Clica en **Usuarios**.

    <div align="left"><figure><img src="../../.gitbook/assets/image (64).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Crear el usuario

* Clica en :heavy\_plus\_sign:.
*   Se abrirá este formulario:<br>

    <figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>

    * **Nombre:** el nombre del usuario.
    * **Logo:** opcional. Una foto del usuario.
    * **Email:** el correo con el que entrará en Taykus.
    * **Contraseña:** su contraseña de acceso.
    * **Lenguaje preferido:** el idioma en el que verá el programa.
    * **Rol:** los permisos que tendrá. Para saber cómo crear o editar un rol, consulta [como-crear-editar-o-borra-un-rol.md](../roles/como-crear-editar-o-borra-un-rol.md "mention").
    * **Página de inicio:** la pantalla que verá al entrar en el programa.
* Clica en **Guardar**.
{% endstep %}
{% endstepper %}
