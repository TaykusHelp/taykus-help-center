# Cómo crear un usuario

Para gestionar el club desde el programa es necesario crear usuarios con acceso al panel administrativo. Cada usuario contará con sus propias credenciales y permisos, lo que permite controlar quién puede acceder, qué puede ver y qué acciones puede realizar dentro del sistema.\
En este artículo encontrarás los pasos para crear nuevos usuarios y configurar correctamente sus niveles de acceso.

{% stepper %}
{% step %}
### Acceso a Usuarios

*   Dirígete al menú de configuración, en la esquina superior derecha, y clica en **Usuarios**.

    <div align="left"><figure><img src="../../.gitbook/assets/image (64).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Creación de usuario

* Haz clic en :heavy\_plus\_sign: para crear un nuevo usuario.
*   Se abrirá un formulario que se debe completar con los siguientes datos:<br>

    <figure><img src="../../.gitbook/assets/image (65).png" alt=""><figcaption></figcaption></figure>

    * **Nombre:** Especifica el nombre del usuario.
    * **Logo:** Si el usuario quiere usar foto, se puede añadir aquí.
    * **Email/ correo electrónico:** Mail con el que el usuario accederá al software.
    * **Contraseña:** Clave de acceso para el nuevo usuario.
    * **Lenguaje Preferido:** Idioma en el que el usuario verá el programa.
    * **Rol:** Permisos que tendrá al acceder al programa.\
      \
      _&#x50;ara saber como crear o editar un rol clicar en el siguiente enlace:_\
      [como-crear-editar-o-borra-un-rol.md](../roles/como-crear-editar-o-borra-un-rol.md "mention")<br>
    * **Página de inicio:** Página principal que visualizará el nuevo usuario cuando inicia el programa.
* Clica Guardar para dejar creado el nuevo usuario.
{% endstep %}
{% endstepper %}
