# Cómo mover columnas

Puedes cambiar el orden de las columnas de un listado para tener a mano las que más usas.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Arrastrar la columna

* Clica en la cabecera de la columna que quieres mover y, sin soltar, arrástrala hacia la izquierda o la derecha.
*   Suéltala en el sitio donde la quieres.

    <figure><img src="../../.gitbook/assets/listados-mover-columna.png" alt=""><figcaption></figcaption></figure>
{% endstep %}
{% endstepper %}

> **Importante:** si arrastras la cabecera hacia arriba, fuera del listado, la columna se oculta. Para volver a mostrarla, consulta [Cómo ocultar o mostrar columnas](como-ocultar-o-mostrar-columnas.md).

Para conservar este orden, guarda el listado como favorito. Consulta [Cómo guardar un listado como favorito](como-guardar-un-listado-como-favorito.md).
