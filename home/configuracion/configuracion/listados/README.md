# Listados

Casi todas las pantallas del panel de Taykus son listados: jugadores, ventas, pagos, deudas, plantillas… Todos funcionan igual, así que lo que aprendas en uno te sirve para los demás.

En cualquier listado puedes:

* [Filtrar entre dos fechas](como-filtrar-entre-dos-fechas.md).
* [Mover columnas](como-mover-columnas.md).
* [Ocultar o mostrar columnas](como-ocultar-o-mostrar-columnas.md).
* [Guardar un listado como favorito](como-guardar-un-listado-como-favorito.md), con sus filtros y columnas.
* [Exportar un listado](como-exportar-un-listado.md).
