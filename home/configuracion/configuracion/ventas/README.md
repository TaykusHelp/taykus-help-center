{% tab title="Cajas" %}
## Cajas

En esta sección <mark style="background-color:$danger;">**no debe realizarse ninguna modificación**</mark>, especialmente en la **Caja Online**. No se deben editar datos ni configuraciones, ya que cualquier cambio puede afectar al correcto funcionamiento del sistema y a la conciliación de cobros.

Esta área es únicamente informativa y sirve para identificar las distintas cajas del club. Desde aquí se pueden crear **cajas independientes para cada usuario**, de modo que cada persona gestione y visualice únicamente sus propios movimientos de efectivo.

Para crear una caja independiente solo hay que seguir este proceso:

{% stepper %}
{% step %}
### Acceso a Configuración de Ventas

* Dirígete al menú de configuración situado en la esquina superior derecha.
* Clica en **Ventas**.
*   Selecciona la pestaña **Cajas.**

    <figure><img src="../../.gitbook/assets/image (27).png" alt=""><figcaption></figcaption></figure>
*   En esta sección nos encontraremos con dos cajas: principal y on-line. <mark style="background-color:$danger;">**NO TOCAR BAJO NINGUN CONCEPTO.**</mark> Cualquier duda, preguntar al equipo de soporte.

    <figure><img src="../../.gitbook/assets/image (25).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear caja personalizada

* Clica en :heavy\_plus\_sign:
*   Emerge una venta que ha de cumplimentarse de la siguiente manera:<br>

    <figure><img src="../../.gitbook/assets/image (26).png" alt=""><figcaption></figcaption></figure>

    * **Nombre:** El título que se le va a dar a esta caja, si es para alguien del personal, se recomienda añadir el nombre de esta persona.
    * **Tipo:** Local.
    * **Hora cierre:** Selecciona la hora a la que se quiera cerrar esta caja de manera automática. Sino se completa este campo, la caja se deberá cerrar siempre de manualmente.
    * **Importes Cierres:** Cantidad sugerida para dejar en la caja cuando se está cerrando.
* Cluca en Guardar para salvar los cambios.
{% endstep %}
{% endstepper %}

{% tab title="Impuestos" %}
## Cómo crear o modificar un impuesto

En este artículo se explica cómo crear y configurar el IVA en el sistema. Definir correctamente los impuestos es fundamental para que los precios se calculen de forma adecuada, las facturas sean correctas y los informes reflejen los importes reales conforme a la normativa fiscal.

{% stepper %}
{% step %}
### Acceso a Configuración de Ventas

* Dirígete al menú de configuración situado en la esquina superior derecha.
* Clica en **Ventas**.
*   Selecciona la pestaña **Impuestos.**

    <figure><img src="../../.gitbook/assets/image (49).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear un impuesto

* Clica en :heavy\_plus\_sign:.
*   Se abre una ventana que se deberá cumplimentar de la siguiente manera:<br>

    <div align="left"><figure><img src="../../.gitbook/assets/image (50).png" alt=""><figcaption></figcaption></figure></div>

    * **Nombre:** el nombre que queramos ponerle al impuesto, aunque como recomendación, el nombre debería ser el porcentaje a retener.
    * **Porcentaje:** el porcentaje de retención.
* Clica en guardar para salvar cambios.
{% endstep %}

{% step %}
### Modificar un impuesto

* Clica en id del impuesto a cambiar.
*   Clica en el icono de editar <i class="fa-pen" style="color:green;">:pen:</i>.<br>

    <figure><img src="../../.gitbook/assets/image (48).png" alt=""><figcaption></figcaption></figure>
* Realiza los cambios.
* Clica en guardar.
{% endstep %}
{% endstepper %}

## Cómo crear o modificar un pie de ticket

En muchos casos, agregar un pie de página a un ticket de compra es útil para incluir información adicional, como términos y condiciones, promociones, agradecimientos o detalles de contacto.

En este artículo vamos a enseñar a cómo hacerlo en nuestro programa:

{% stepper %}
{% step %}
### Acceso a Configuración de Ventas

* Dirígete al menú de configuración situado en la esquina superior derecha.
* Clica en **Ventas**.
*   Selecciona la pestaña **Ticket.**<br>

    <figure><img src="../../.gitbook/assets/image (46).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Añadir pie de ticket

* Clica en <i class="fa-pencil" style="color:green;">:pencil:</i>.
*   En este apartado es donde debe escribirse lo que se quiera añadir al pie del ticket<br>

    <figure><img src="../../.gitbook/assets/image (47).png" alt=""><figcaption></figcaption></figure>
* Clica en guardar para salvar cambios.
{% endstep %}
{% endstepper %}

**IMPORTANTE:** Solo se puede añadir un pie de ticket.
