# Cómo modificar el precio de un producto de tipo artículo

Los productos tipo **Artículo** son aquellos productos que el club puede vender desde el sistema, como botes de bolas, grips u otros productos físicos.

Desde el apartado de **Productos** es posible modificar su precio de forma sencilla. Al cambiar el **Precio Bruto**, el sistema recalcula el **Precio Neto** según el tipo de impuesto configurado en el producto.

{% step %}
### Acceso a configuración de ventas

* Dirígete al menú de configuración situado en la esquina superior derecha.
* Clica en **Ventas** y directamente, se redirigirá a la pestaña de **Productos**.
{% endstep %}

{% step %}
### Búsqueda del artículo

Para localizar el producto de forma más rápida, puedes utilizar los filtros disponibles en el listado.

* En la columna **Categoría**, selecciona la opción **Artículo**.
*   En la columna **Nombre**, escribe el nombre completo o parte del nombre del producto que quieres buscar.

    Por ejemplo: `bote`

El sistema mostrará únicamente los productos que coincidan con esos filtros.
{% endstep %}

{% step %}
### Editar el precio desde el listado (Opción 1)

Una vez localizado el artículo:

* Busca la columna **Precio Bruto**.
* Haz clic sobre el precio actual del producto.
* Introduce el nuevo importe.
* Pulsa fuera del campo para que el cambio quede aplicado.
* Comprueba que el precio se ha actualizado correctamente en el listado.

El **Precio Neto** se actualizará en función del impuesto asignado al producto.
{% endstep %}

{% step %}
### Editar el precio desde la ficha del producto (Opción 2)

También puedes modificar el precio entrando directamente en la ficha del artículo.

* Haz clic sobre el **ID** del producto que quieres editar.
* Dentro de la ficha, accede a la pestaña **General**.
* Pulsa el icono de **editar**.
* Modifica el campo **Precio Bruto**.
* Pulsa **Guardar** para aplicar los cambios.

Una vez guardado, el producto volverá a mostrarse con el nuevo precio configurado.
{% endstep %}
{% endstepper %}

Antes de guardar el cambio, revisa que el producto seleccionado sea el correcto, especialmente si existen varios artículos con nombres parecidos.

También es importante comprobar el campo **Tipo de impuestos**, ya que el **Precio Neto** se calcula a partir del **Precio Bruto** y del impuesto configurado.

Una vez realizado el cambio, el artículo quedará actualizado con el nuevo precio y podrá utilizarse en ventas con la configuración modificada.
