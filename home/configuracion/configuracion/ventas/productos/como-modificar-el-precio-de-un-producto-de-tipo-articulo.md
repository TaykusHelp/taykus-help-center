# Cómo modificar el precio de un producto de tipo artículo

Puedes cambiar el precio de cualquier artículo (botes de bolas, grips u otros productos) desde el listado de productos o desde su ficha. Al cambiar el **Precio bruto**, el sistema recalcula el **Precio neto** según el impuesto del producto.

### Vídeo explicativo

{% embed url="https://youtu.be/dnUlgHbHzDk" %}

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Productos

* Clica en el icono <i class="fa-gear" style="color:blue;">:gear:</i> de la esquina superior derecha y entra en **Configuración**.
* Clica en **Ventas**. Se abrirá directamente la pestaña **Productos**.
{% endstep %}

{% step %}
### Buscar el artículo

* En la columna **Categoría**, selecciona **Artículo**.
* En la columna **Nombre**, escribe el nombre o parte del nombre del producto. Por ejemplo: `bote`.
* El listado mostrará solo los productos que coincidan.
{% endstep %}

{% step %}
### Opción 1: Cambiar el precio desde el listado

* En la columna **Precio bruto**, clica sobre el precio actual.
* Escribe el nuevo importe.
* Clica fuera del campo para aplicar el cambio.
* Comprueba en el listado que el precio se ha actualizado.
{% endstep %}

{% step %}
### Opción 2: Cambiar el precio desde la ficha

* Clica sobre el **ID** del producto.
* Abre la pestaña **General**.
* Pulsa el icono de editar.
* Cambia el **Precio bruto**.
* Clica en **Guardar**.
{% endstep %}
{% endstepper %}

> **Importante:** antes de guardar, comprueba que has elegido el producto correcto (sobre todo si hay varios con nombres parecidos) y revisa su **Tipo de impuesto**, porque el precio neto se calcula a partir de él.
