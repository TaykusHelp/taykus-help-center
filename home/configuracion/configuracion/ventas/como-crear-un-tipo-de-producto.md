# Cómo crear un Tipo de producto

Los tipos de producto sirven para clasificar y organizar los productos dentro del sistema. Gracias a esta categorización es posible agruparlos, identificarlos fácilmente y analizarlos después en informes de ventas, estadísticas y resultados, facilitando el control y la toma de decisiones.

{% stepper %}
{% step %}
### Acceso a Configuración de Ventas

* Dirígete al menú de configuración situado en la esquina superior derecha.
* Clica en **Ventas**.
*   Selecciona la pestaña **Tipos de productos.**<br>

    <figure><img src="../../.gitbook/assets/image (93).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear un tipo de producto

* Clica en :heavy\_plus\_sign:.
*   Se abre una ventana que se deberá cumplimentar con el nombre de la nueva categoría o subfamilia.

    <div align="left"><figure><img src="../../.gitbook/assets/image (94).png" alt=""><figcaption></figcaption></figure></div>
* Clica en guardar para salvar cambios.
{% endstep %}

{% step %}
#### Modificar un tipo de producto <a href="#modificar-un-impuesto" id="modificar-un-impuesto"></a>

* Clica en id del tipo de producto a cambiar.
* Clica en el icono de editar <i class="fa-pen" style="color:green;">:pen:</i>.
* Realiza los cambios.
* Clica en guardar.


{% endstep %}
{% endstepper %}
