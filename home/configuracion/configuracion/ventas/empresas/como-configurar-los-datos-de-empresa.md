# Cómo configurar los datos de empresa

En esta sección podrás configurar los datos fiscales de tu empresa, que serán los que se utilizarán automáticamente en la autofactura que se genera cuando el club solicite una transferencia.\
Solo es posible registrar una única empresa o razón social. Estos datos suelen quedar definidos durante la configuración inicial del programa, pero desde aquí podrás revisarlos y modificarlos siempre que sea necesario.\
\
Es fundamental que la información esté completa y correctamente actualizada, ya que aparecerá en todos los documentos contables y justificantes emitidos por el sistema.

{% stepper %}
{% step %}
### Acceso a Configuración de empresas

* Dirígete al menú de configuración situado en la esquina superior derecha.
* Clica en **Ventas**.
*   Selecciona la pestaña **Empresas.**<br>

    <figure><img src="../../../.gitbook/assets/image (111).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear datos de empresa

*   Clica en :heavy\_plus\_sign:<br>

    <figure><img src="../../../.gitbook/assets/image (112).png" alt=""><figcaption></figcaption></figure>
* Completamos con los datos fiscales de la empresa. El único campo obligatorio es el mail
  * <mark style="background-color:$danger;">**NOTA IMPORTANTE:**</mark> <mark style="background-color:$danger;"></mark><mark style="background-color:$danger;">no tocar el Invoice Number Format.</mark>
* Clica guardar para terminar.
{% endstep %}
{% endstepper %}

Una vez se hayan seguido estos pasos, la empresa quedará creada y cada vez que se solicite una transferencia y se genere una auto-factura, se verán plasmados dichos datos.
