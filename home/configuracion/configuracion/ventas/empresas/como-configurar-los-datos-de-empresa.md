# Cómo configurar los datos de empresa

Aquí se guardan los datos fiscales del club. Se usan automáticamente en la autofactura que se genera cuando el club solicita una transferencia, y aparecen en todos los documentos contables que emite el sistema.

Solo se puede registrar **una empresa o razón social**. Normalmente estos datos se configuran al empezar con Taykus, pero puedes revisarlos y cambiarlos cuando lo necesites.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Empresas

* Clica en el icono <i class="fa-gear" style="color:blue;">:gear:</i> de la esquina superior derecha y entra en **Configuración**.
* Clica en **Ventas**.
*   Abre la pestaña **Empresas**.<br>

    <figure><img src="../../../.gitbook/assets/image (111).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear los datos de empresa

*   Clica en :heavy\_plus\_sign:.<br>

    <figure><img src="../../../.gitbook/assets/image (112).png" alt=""><figcaption></figcaption></figure>
* Completa los datos fiscales de la empresa. El único campo obligatorio es el **email**.

> **Importante:** <mark style="background-color:$danger;">no modifiques el campo **Invoice Number Format**.</mark>
{% endstep %}

{% step %}
### Guardar

* Clica en **Guardar**.
* A partir de ahora, estos datos aparecerán en cada autofactura que se genere al solicitar una transferencia.
{% endstep %}
{% endstepper %}
