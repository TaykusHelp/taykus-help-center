# Cómo editar los datos de una empresa cliente

Si cambian los datos de una empresa cliente (dirección, CIF, contacto…), puedes actualizarlos en cualquier momento. Los nuevos datos se usarán en las próximas facturas.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Empresas clientes <a href="#acceso-a-configuracion-de-empresas" id="acceso-a-configuracion-de-empresas"></a>

* Clica en el icono <i class="fa-gear" style="color:blue;">:gear:</i> de la esquina superior derecha y entra en **Configuración**.
* Clica en **Ventas**.
*   Abre la pestaña **Empresas clientes**.<br>

    <figure><img src="../../../.gitbook/assets/image (113).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Editar los datos

* Clica sobre el **ID** de la empresa cliente.
*   Selecciona <i class="fa-pen" style="color:blue;">:pen:</i>.<br>

    <figure><img src="../../../.gitbook/assets/image (108).png" alt=""><figcaption></figcaption></figure>
*   Cambia los datos que necesites.

    <figure><img src="../../../.gitbook/assets/image (109).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Guardar

* Clica en **Guardar**.
{% endstep %}
{% endstepper %}
