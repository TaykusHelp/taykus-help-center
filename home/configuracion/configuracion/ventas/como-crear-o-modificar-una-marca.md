# Cómo crear o modificar una marca

Categorizar por marcas sirve para clasificar y organizar los productos dentro del sistema. Gracias a esta categorización es posible agruparlos, identificarlos fácilmente y analizarlos después en informes de ventas, estadísticas y resultados, facilitando el control y la toma de decisiones.

{% stepper %}
{% step %}
### Acceso a Configuración de Ventas

* Dirígete al menú de configuración situado en la esquina superior derecha.
* Clica en **Ventas**.
*   Selecciona la pestaña **Marcas.**<br>

    <figure><img src="../../.gitbook/assets/image (95).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear una marca

* Clica en :heavy\_plus\_sign:.
*   Se abre una ventana que se deberá cumplimentar con el nombre de la marca.

    <div align="left"><figure><img src="../../.gitbook/assets/image (94).png" alt=""><figcaption></figcaption></figure></div>
* Clica en guardar para salvar cambios.
{% endstep %}

{% step %}
### Modificar una marca

* Clica en id de la marca a cambiar.
* Clica en el icono de editar <i class="fa-pen" style="color:green;">:pen:</i>.
* Realiza los cambios.
* Clica en guardar.


{% endstep %}
{% endstepper %}
