# Personalizar precio de reservas por minutos de juego

Puedes fijar un precio distinto para una reserva según su duración, sin tener que crear un producto nuevo para cada duración.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Productos

* Clica en el icono <i class="fa-gear" style="color:blue;">:gear:</i> de la esquina superior derecha y entra en **Configuración**.
* Clica en **Ventas**. Se abrirá directamente la pestaña **Productos**.
{% endstep %}

{% step %}
### Abrir el producto

* Busca en el listado el producto al que quieres aplicar el precio especial.

> **Importante:** elige bien el producto. En las reservas suele haber un servicio por franja (hora punta, hora valle…), así que asegúrate de abrir el servicio y la franja exactos a los que quieres aplicar el precio.

*   Clica sobre su **ID**. Se abrirá la pestaña **General** del producto.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (90).png" alt=""><figcaption></figcaption></figure></div>
*   Abre la pestaña **Precios especiales**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (91).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Crear el precio especial

* Clica en :heavy\_plus\_sign:.
*   Se abrirá una ventana en la que solo tienes que completar estos campos:<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure></div>

    * **Minutos:** la duración a la que se aplica el nuevo precio. Por ejemplo, 60, 120 o 180.
    * **Precio bruto:** el nuevo precio, en números. Si quieres que sea gratis, pon 0.
* Clica en **Guardar**.
{% endstep %}
{% endstepper %}

> Si quieres un precio distinto para cada duración, crea un precio especial para cada una: uno para 60 minutos, otro para 120, otro para 180… Y si debe aplicarse en varias franjas o en varios productos, repite el proceso en cada uno.
