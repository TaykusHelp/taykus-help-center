# Cómo modificar los precios

Los precios de las reservas dependen de las franjas configuradas en **Precios por calendario**. Para cambiar un precio, cambias el producto que usa esa franja. Antes de empezar, asegúrate de que vas a editar el calendario, las instalaciones y las franjas correctas.

### Vídeo explicativo

{% embed url="https://youtu.be/Ra_LiCtxGUY" %}

> **Antes de empezar:** el nuevo precio tiene que existir como producto de tipo Servicio. Si todavía no lo has creado, consulta:
>
> <a href="../../ventas/productos/como-crear-un-producto-tipo-servicio.md" class="button primary" data-icon="box">Cómo crear un producto tipo Servicio</a>

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Precios por calendario

* Clica en el icono <i class="fa-gear" style="color:blue;">:gear:</i> de la esquina superior derecha y entra en **Configuración**.
*   Clica en **Reservas**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (56).png" alt=""><figcaption></figcaption></figure></div>
*   Clica en el bloque **Precios por calendario**.<br>

    <figure><img src="../../../.gitbook/assets/image (74).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Abrir el calendario de precios

* Busca el calendario de precios que quieres cambiar y clica sobre su **ID**.
*   Ve al bloque **Precios**.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure></div>
* Verás el listado de franjas con su precio:

<figure><img src="../../../.gitbook/assets/image.png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Opción 1: Cambiar el producto de una franja

* Ensancha la columna **Productos** arrastrando su borde hacia la derecha.
*   Clica en el espacio en blanco señalado.<br>

    <figure><img src="../../../.gitbook/assets/image (2).png" alt=""><figcaption></figcaption></figure>
*   Clica en la **X** para quitar el producto actual.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (3).png" alt=""><figcaption></figcaption></figure></div>
* Busca el producto con el nuevo precio.  ![](<../../../.gitbook/assets/image (5).png>)
* Selecciónalo y pulsa **Enter**. La franja quedará actualizada.
{% endstep %}

{% step %}
### Opción 2: Crear una franja nueva

También puedes borrar las franjas actuales y crear otras nuevas.

* Clica en :heavy\_plus\_sign:.
*   Se abrirá la ventana **Añadir hora**:<br>

    <figure><img src="../../../.gitbook/assets/image (1).png" alt=""><figcaption></figcaption></figure>

    * **Recurso:** la pista o recurso concreto, si el precio es solo para uno.
    * **Grupo de recurso:** el grupo, si el precio es para varias instalaciones del mismo tipo.
    * **Inicio:** hora en la que empieza a aplicarse el precio.
    * **Fin:** hora en la que deja de aplicarse.
    * **Finaliza el día siguiente:** márcala si la franja termina al día siguiente.
    * **Aplicar este precio en solapamientos:** márcala si este precio debe aplicarse cuando dos franjas coincidan.
    * **Producto:** el producto que marca el precio de las reservas en esta franja.
* Clica en **Guardar**.
{% endstep %}

{% step %}
### Comprobar los cambios

Revisa en el listado de precios que la franja está bien. Comprueba sobre todo:

* Que el recurso o grupo de recursos es el correcto.
* Que la hora de inicio y de fin están bien.
* Que el producto es el adecuado y su precio es el que quieres cobrar.
* Que la opción de solapamientos está marcada solo si hace falta.
{% endstep %}
{% endstepper %}
