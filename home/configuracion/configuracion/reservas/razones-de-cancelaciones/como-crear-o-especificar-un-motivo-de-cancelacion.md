# Cómo crear o especificar un motivo de Cancelación

Cada vez que un usuario cancela una reserva, suele haber un motivo detrás: un imprevisto, un cambio de horario, una lesión, una mala previsión…\
\
La sección de _Razones de cancelación_ permite definir y registrar estos motivos, de forma que el club pueda entender por qué se producen las cancelaciones, analizar patrones y mejorar la gestión de horarios, recursos y comunicación con los jugadores.

Para configurarlo solo tenemos que seguir estos pasos:

{% stepper %}
{% step %}
### Acceso a Configuración de reservas

* Dirígete a la esquina superior derecha y clica en el icono de Configuración.
* En el desplegable que se abre, selecciona configuración.
*   Luego accede a **Reservas.**

    <div align="left"><figure><img src="https://taykus-help-center.gitbook.io/taykushelpcenter/~gitbook/image?url=https%3A%2F%2F2372912666-files.gitbook.io%2F%7E%2Ffiles%2Fv0%2Fb%2Fgitbook-x-prod.appspot.com%2Fo%2Fspaces%252FV0h7jTfpeuZY1RmPEtNK%252Fuploads%252Fo7gBVkwfX7ziYiTLefsN%252Fimage.png%3Falt%3Dmedia%26token%3D9f9d15bf-ab2d-44e1-b2e8-fd7276f24e60&#x26;width=300&#x26;dpr=4&#x26;quality=100&#x26;sign=3f7de3b8&#x26;sv=2" alt=""><figcaption></figcaption></figure></div>


*   Localiza el bloque **Razones de Cancelación** y haz clic.<br>

    <figure><img src="../../../.gitbook/assets/image (120).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear razones de cancelación

* Clica en :heavy\_plus\_sign:
*   Se abre una ventana en la se deberá escribir el cómo se quiere nombrar a este motivo de cancelación, ejemplo: _lluvia, enfermedad, mantenimiento de pista, olvido, etc._<br>

    <figure><img src="../../../.gitbook/assets/image (28).png" alt=""><figcaption></figcaption></figure>
* Clica en guardar para salvar cambios.
* Se pueden crear tantos como motivos gusten.
{% endstep %}

{% step %}
### Poner un motivo de cancelación a una reserva

*   Siempre que se cancela una reserva emerge la siguiente pantalla:<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (29).png" alt=""><figcaption></figcaption></figure></div>


* No es obligatorio aportar una razón de cancelación pero es desde aquí donde se puede seleccionar en el desplegable los motivos ya creados.
{% endstep %}

{% step %}
### Sacar listado de razones de cancelación

* Para sacar este listado hay que clicar en Calendario.
* Se abre un desplegable y hay que seleccionar **Reservas.**\
  ![](<../../../.gitbook/assets/image (30).png>)
* Clica en Columnas y selecciona **Motivos de Cancelación** para que la muestre en el listado.\
  ![](<../../../.gitbook/assets/image (31).png>)
*   Filtra por estado **Cancelado** y ya se obtiene el listado, que se mostraría de la siguiente manera:<br>

    <figure><img src="../../../.gitbook/assets/image (33).png" alt=""><figcaption></figcaption></figure>
* El listado que aparece se puede descargar y exportar a Excel.<br>
{% endstep %}
{% endstepper %}
