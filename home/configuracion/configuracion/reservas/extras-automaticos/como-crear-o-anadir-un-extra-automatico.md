# Cómo crear o añadir un extra automático

Un **extra automático** es un suplemento que se suma solo al precio de la reserva en determinadas condiciones. Por ejemplo, cobrar la luz aparte a partir de cierta hora o en ciertas fechas.

> **Antes de empezar:** el extra tiene que existir como producto de tipo Servicio. Si todavía no lo has creado, consulta:
>
> [como-crear-un-producto-tipo-servicio.md](../../ventas/productos/como-crear-un-producto-tipo-servicio.md "mention")

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Extras automáticos

* Clica en el icono <i class="fa-gear" style="color:blue;">:gear:</i> de la esquina superior derecha y entra en **Configuración**.
*   Clica en **Reservas**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (37).png" alt=""><figcaption></figcaption></figure></div>
*   Clica en el bloque **Extras automáticos**.<br>

    <figure><img src="../../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Crear el extra

* Clica en :heavy\_plus\_sign:.
*   Se abrirá esta ventana:

    <figure><img src="../../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

    * **Producto:** busca el producto que quieres sumar como extra.
    * **Tipo de reserva:** el tipo de reserva al que se aplica. Si quieres aplicarlo a varios tipos, crea un extra para cada uno.
    * **Recurso:** las pistas a las que se suma. Si lo dejas vacío, se aplica a todas.
    * **Tipo de cliente:** si solo se cobra a un tipo de cliente (por ejemplo, socio o no socio).
    * **Cliente:** si solo se cobra a una persona. Si son varias, crea un extra para cada una.
    * **Fecha de inicio:** desde qué fecha se suma.
    * **Fecha fin:** hasta qué fecha. Es opcional.
    * **Hora de inicio:** a partir de qué hora se suma.
    * **Hora de fin:** hasta qué hora. Es opcional.
    * **Recurrencia anual:** márcala si se repite todos los años.
    * **Días de la semana:** los días en los que se suma.
* Clica en **Guardar**.
{% endstep %}
{% endstepper %}

> **Importante:** igual que en los productos se crea uno para reservas y otro para partidos, aquí también tienes que crear un extra para cada uno. Primero crea los dos productos y después los dos extras.
