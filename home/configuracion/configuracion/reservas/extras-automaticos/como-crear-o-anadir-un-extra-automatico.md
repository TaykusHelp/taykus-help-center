# Cómo crear o añadir un extra automático

Un extra automático es un servicio, que se le quiere añadir como suplemento al precio de la reserva, como por ejemplo: el precio de la luz a parte y que se cobre a partir de determinadas horas y en determinadas fechas.

Para ello, lo primero que deberemos hacer es crear el producto, así que nos iremos a:

{% stepper %}
{% step %}
### Acceso a Configuración de extras automáticos

* Dirígete a la esquina superior derecha y clica en el icono de **Configuración**.
* En el desplegable que se abre, selecciona **configuración**.
*   Luego accede a **Reservas**.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (37).png" alt=""><figcaption></figcaption></figure></div>
*   Localiza el bloque **Precios por Calendario** y haz clic.<br>

    <figure><img src="../../../.gitbook/assets/image (38).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Configurar el extra automático

* Clica en :heavy\_plus\_sign:.
*   Emerge una venta que ha de cumplimentarse de la siguiente manera:

    <figure><img src="../../../.gitbook/assets/image (39).png" alt=""><figcaption></figcaption></figure>

    * **Producto:** buscamos el nombre del producto previamente creado.
      * _Si no se tiene el producto previamente creado visita el siguiente enlace para saber como crearlo:_\
        [como-crear-un-producto-tipo-servicio.md](../../ventas/productos/como-crear-un-producto-tipo-servicio.md "mention")
      * _**Nota importante:** Al igual que en productos creamos uno para partido y otro para reservas, en este apartado deberemos de hacer lo mismo. Primero, crear los dos productos y luego los dos extras._
    * **Tipo de reserva:** seleccionaremos el tipo de reserva al que queremos que se le aplique dicho extra. Deberemos de crear tantos extras como tipos de reserva a los que queremos que se le sume.
    * **Recurso:** aquí seleccionamos al número de pistas a las que queremos sumarle el extra, sino rellenamos este espacio, se aplicará de manera automática a todas.
    * **Tipo de cliente:** por si queremos que solo se le cobre a un tipo de cliente en concreto (socio/ no socio).
    * **Cliente:** si solo queremos que se le aplique exclusivamente a una persona. Si son varias personas, deberemos de crear tantos extras como personas a las que queremos añadir dicho suplemento.
    * **Fecha de inicio:** a partir de qué fecha queremos que se le añada.
    * **Fecha fin:** no es un requisito obligatorio, pero es cuando queremos que finalice.
    * **Hora de inicio:** a partir de qué hora queremos que se empiece a sumar.
    * **Hora de fin:** al igual que la fecha de fin, no es un requisito obligatorio.
    * **Recurrencia anual:** si queremos que se repita todos los años.
    * **Días de la semana:** señalamos los días en los que queremos que se haga este incremento.
* Clica en guardar para salvar los cambios.
{% endstep %}
{% endstepper %}
