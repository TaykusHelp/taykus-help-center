# Cómo crear un recurso

Normalmente en la configuración inicial para empezar a utilizar el programa ya se incluyen las instalaciones de las que consta el centro, 3 pistas de padal, 2 pistas de tenis, 2 campos de fútbol, etc.

El módulo de reservas permite crear **recursos**, que pueden ser tanto las pistas, deportes y los profesores. Un recurso es aquello que los usuarios pueden reservar o lo que necesitas asignar a una actividad. Al configurarlos aquí, el sistema sabe qué está disponible, en qué horarios y cómo gestionarlo. Es la base para organizar reservas de forma ordenada y sin solapamientos.

Si se necesita crear algún nuevo recurso solo hay que seguir estos pasos:

{% stepper %}
{% step %}
### Acceso a la configuración

* Dirígete al menú de configuración situado en la esquina superior derecha.
* Clica en **Reservas** y directamente, se redirigirá al bloque de Grupo de Recursos.
{% endstep %}

{% step %}
### Crear deporte

* Clica en <i class="fa-plus-large">:plus-large:</i> para crear un nuevo deporte/no deporte.
*   Se abrirá la siguiente ventana que ha de ser cumplimentada de esta forma:

    * **Nombre:** el nombre del deporte en cuestión, en este ejemplo lo vamos a ver con el tenis.\
      Si queremos crear profesores, seleccionamos **No Deporte.**

    <figure><img src="../../../.gitbook/assets/image (68).png" alt=""><figcaption></figcaption></figure>

    *   **Orden:** el orden en el que queremos que se vea el recurso en el calendario.

        <figure><img src="../../../.gitbook/assets/image (67).png" alt=""><figcaption></figcaption></figure>
    * **Deporte:** el deporte en cuestión.
    * **Categoría:** seleccionamos el tipo de recurso.
    * **Intervalos en minutos**: En cada cuantos minutos se quiere que se divida el calendario.
    * **Duración mínima:** la duración mínima que puede tener el partido/reserva.
    * **Duración máxima:** el tiempo máximo que puede durar una reserva.
* Estos son los campos obligatorios a rellenar.
{% endstep %}

{% step %}
### Campos opcionales

* Hay otros campos también importantes y opcionales:
  * **Modifica Nivel:** si se quiere que este deporte suba o baje el nivel del jugador al introducir el resultado.
  * **Alto celda Calendario:** La altura de las celdas en el calendario. El valor recomendado para visualizar 4 jugadores de 1 hora de duración es franjas de 30mins es de 90. Por defecto 35.
  * **Mostrar jugadores**: Hacer clic si se quiere mostrar jugadores directamente en la reserva del calendario.
  * **Discontinuado:** Hacer clic si se quiere descatalogar.
  * **Mostrar iniciales Participantes:** haz clic si se desea que en el display aparezcan las iniciales y no el nombre completo.
  * **Máximo tiempo entre reservas online:** Espacio mínimo que se puede dejar libre entre una reserva hecha online y otra.
  * **Espacio entre reservas en Apertura/ Cierre**: Comprueba el espacio mínimo que se puede dejar entre reservas pero teniendo en cuenta además el espacio con la apertura y cierre de la instalación.
  * **Tiempo Min. entre Reservas Admin:** Espacio mínimo que se puede dejar libre entre una reserva hecha desde administración y otra.
  * **Hora inicio día:** Hora a la que empieza el día. El valor debe ser un número entero entre 0 y 23.
{% endstep %}

{% step %}
### Añadir recursos

* Clica sobre el id del deporte/ no deporte.
*   Dirígete al bloque de recursos.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (69).png" alt=""><figcaption></figcaption></figure></div>
* Clica en <i class="fa-plus-large">:plus-large:</i> para crear un nuevo recurso.
* Se abre otra ventana que deberá cumplimentarse de la siguiente manera:
  * **Nombre:** el nombre que queremos que tenga la pista, lo ideal, es que tenga el nombre del deporte y su número, pero si la pista está patrocinada, la titularemos con el nombre del patrocinio.
  * **Orden:** el orden en que queremos que nos aparezca la pista en el calendario.
  * **Tipo de pista:** Si es interior, exterior, cubierta, etc.
  * **Suelo/ Pared:** Este apartado va a depender del deporte, si estamos hablando de tenis o futbol, por ejemplo, nos preguntará el tipo de suelo. Si, por el contrario, hablamos de pádel o de squash, se referirá al tipo de pared. Simplemente pulsamos y señalamos la opción correcta en el desplegable.
  *   **Guardamos y nuevo:** si tenemos que crear más de una pista, para no tener que guardar y darle a nuevo, podemos señalar esta opción y se guarda casi todo lo que hayamos hecho, salvo el nombre y el orden.

      <figure><img src="../../../.gitbook/assets/image (72).png" alt=""><figcaption></figcaption></figure>


{% endstep %}
{% endstepper %}
