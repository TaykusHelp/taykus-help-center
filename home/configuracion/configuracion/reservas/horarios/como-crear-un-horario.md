# Cómo crear un horario

Para que nuestras instalaciones aparezcan en el calendario, una vez ya creadas, es necesario que le demos un horario.

El programa siempre va a tener, ya creados, dos horarios predeterminados, por lo tanto, o bien podemos modificarlo o podemos eliminarlos y crear uno nuevo.

### Video Explicativo

{% embed url="https://youtu.be/0UDRdOUjr54" %}

En este artículo te mostramos los pasos para crear un horario desde cero:

{% stepper %}
{% step %}
### Acceso a Configuración de Reservas

* Dirígete a la esquina superior derecha y clica en el icono de Configuración.
* En el desplegable que se abre, selecciona configuración.
*   Luego accede a Reservas.

    <div align="left"><figure><img src="../../../.gitbook/assets/image (40).png" alt=""><figcaption></figcaption></figure></div>


*   Localiza el bloque Horarios y haz clic.<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (41).png" alt=""><figcaption></figcaption></figure></div>
{% endstep %}

{% step %}
### Crea un nuevo horario

*   Se abre una ventana para cumplimentar de la siguiente manera:<br>

    <div align="left"><figure><img src="../../../.gitbook/assets/image (42).png" alt=""><figcaption></figcaption></figure></div>



    * **Nombre:** pues aquí dependerá del día o los días que queramos incluir en este horario.
    * **Prioridad**: en el caso de que se solapen dos criterios, cual es el que queremos que priorice, siempre solemos darle más prioridad a los fines de semana, ya que si, por ejemplo, queremos que un día festivo, que cae entre semana, se comporte como un día del fin de semana, al tener este horario más prioridad, este día actuaría como tal.
    * **Inicio/ Fin:** si queremos poner este horario a partir de una fecha o si queremos que termine en determinada fecha, si dejamos estos campos vacíos, se harán efectivos desde el momento en que guardemos.
    * **Día de la Semana:** Señalamos los días que queramos incluir en este horario.
* Clica en guardar.
{% endstep %}

{% step %}
### Horas de apertura y cierre

* Al clicar en guardar, en el paso anterior, se abre la pestaña de Fechas dentro del horario.
*   Clica sobre la pestaña **Horas de Apertura.**

    <div align="left"><figure><img src="../../../.gitbook/assets/image (43).png" alt=""><figcaption></figcaption></figure></div>


* Es importante tener en cuenta qué vamos a configurar:
  * **Horario de apertura y cierre del club:** en este paso se le indicará al programa, las instalaciones (pádel, tenis, futbol) que queramos que tengan este horario determinado. La hora de apertura y la de cierre.
    * <sub>_<mark style="background-color:yellow;">**Nota importante:**</mark>_</sub><sub>_&#x20;<mark style="background-color:yellow;"></mark>_</sub><sub>_<mark style="background-color:yellow;">si tenemos escuela, en el horario, tenemos que añadir a los profesores.</mark>_</sub>
    * <sub>_<mark style="background-color:yellow;">**Nota importante:**</mark>_</sub><sub>_&#x20;<mark style="background-color:yellow;"></mark>_</sub><sub>_<mark style="background-color:yellow;">podemos crear tantos horarios como queramos, si todas las instalaciones tiene el mismo horario, lo incluimos en uno y si cada instalación tiene su propio horario, crearemos más.</mark>_</sub>
  * **Intervalos y Duración de Reservas Online:** aquí indicaremos como queremos que los jugadores puedan reservar online, si pudieran reservar en intervalos de 30, 60 o 90 min, además de la duración mínima y máxima de las pistas.
{% endstep %}

{% step %}
### Añadir horas de apertura y cierre

* Clica en :heavy\_plus\_sign:
*   Se abre una ventana para cumplimentar de la siguiente manera:<br>

    <figure><img src="../../../.gitbook/assets/image (45).png" alt=""><figcaption></figcaption></figure>

    * **Recurso:** se añaden todas las pistas o profesores a los que se vaya a aplicar este horario.
    * **Inicio:** hora de inicio de este horario.
    * **Fin:** hora de finalización de este horario.
    * **Finaliza al dia siguiente:** marca la esta casilla si este horario termina igual o mayor que las 00:00
    * **Intervalos en minutos:** Define cada cuántos minutos se divide el calendario en bloques de tiempo disponibles para reservar. Por ejemplo, un intervalo de 30 minutos mostrará franjas de 09:00, 09:30, 10:00, 10:30, etc., sobre las que se construirán las reservas.
    * **Duración mínima:** Indica el tiempo mínimo que debe durar una reserva. No puede ser menor que el intervalo y tiene que ser múltiplo de este.
    * **Duración máxima:** Indica el tiempo máximo que puede durar una reserva. Tiene que ser múltiplo del intervalo.
* Clica en guardar para salvar los cambios.
{% endstep %}
{% endstepper %}
