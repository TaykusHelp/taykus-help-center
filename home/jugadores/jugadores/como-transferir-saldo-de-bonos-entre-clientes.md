# Cómo transferir saldo de Bonos entre clientes

Una funcionalidad que puede enriquecer la experiencia del usuario es la opción de transferir su saldo de bonos a otro cliente o jugador de su elección. Aunque el usuario no podrá realizar la transferencia de manera autónoma, podrá contactar al club para gestionar la solicitud y asegurar que todo quede registrado correctamente en el sistema.

Este proceso es sencillo y se realza siguiendo estos pasos:

{% stepper %}
{% step %}
### Acceso a jugadores

* Dirígete a la columna de la izquierda y selecciona Jugadores.
{% endstep %}

{% step %}
### Buesqueda del jugador o cliente

*   Utiliza cualquiera de las columnas disponibles para buscar al jugador por nombre, apellido, correo, DNI, etc. y haz clic en su ID.<br>

    <figure><img src="../.gitbook/assets/image (6).png" alt=""><figcaption></figcaption></figure>
* También puedes usar el buscador en la esquina superior izquierda, escribir el nombre del jugador y pulsar Enter.\
  ![](<../.gitbook/assets/image (7).png>)
{% endstep %}

{% step %}
### Acceder a la sección de bonos

* Dentro del perfil del jugador, localiza el bloque de **Facturación.**
*   En el desplegable, selecciona **Bonos**.<br>

    <figure><img src="../.gitbook/assets/image (101).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Transferencia de saldo

* Selecciona el ID del bono del cual deseas realizar la transferencia.
*   En la esquina superior derecha, haz clic en Transferir.<br>

    <div align="left"><figure><img src="../.gitbook/assets/image (9).png" alt=""><figcaption></figcaption></figure></div>


{% endstep %}

{% step %}
### Selecciona el importe a transferir

* Aparecerá una ventana que debes completar con la siguiente información:\
  ![](<../.gitbook/assets/image (102).png>)
  * **Balance:** ingresa la cantidad que deseas transferir.
  * **Jugador:** escribe el nombre del jugador al que se transferirá el saldo.
* Clica en OK para realizar la transferencia.


{% endstep %}
{% endstepper %}
