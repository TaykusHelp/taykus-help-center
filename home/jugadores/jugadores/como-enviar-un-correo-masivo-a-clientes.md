# Cómo enviar un correo masivo a clientes

Desde el listado de jugadores puedes filtrar a tus clientes y enviarles el mismo correo a todos a la vez. Es muy útil para comunicar novedades, avisos o promociones del club.

A continuación, se detallan los pasos a seguir:

{% stepper %}
{% step %}
### Acceso a Jugadores

* Dirígete al menú lateral izquierdo y selecciona **Jugadores**.

<figure><img src="../.gitbook/assets/image (92).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Filtrar a los jugadores

* Usa los filtros de cada columna para quedarte con los jugadores a los que quieres escribir.

<div align="left"><figure><img src="../.gitbook/assets/image (95).png" alt=""><figcaption></figcaption></figure></div>

> Este paso es opcional. Si quieres escribir a todos los jugadores, sáltatelo.
{% endstep %}

{% step %}
### Seleccionar a los destinatarios

* Marca la casilla que hay junto a **Id**, en la cabecera del listado. Se seleccionan todos los jugadores del listado.

<figure><img src="../.gitbook/assets/image (96).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Abrir el envío de email

* Clica en el icono del sobre y elige **Email**.

<figure><img src="../.gitbook/assets/image (97).png" alt=""><figcaption></figcaption></figure>
{% endstep %}

{% step %}
### Redactar el correo

Se abre la ventana **Enviar Mensaje**:

<div align="left"><figure><img src="../.gitbook/assets/image (98).png" alt=""><figcaption></figcaption></figure></div>

* **Destinatario:** salen todos los jugadores que has seleccionado.
* **Plantilla:** si tienes una plantilla creada para este mensaje, elígela aquí y el asunto y el texto se rellenan solos. Para saber cómo crearla, consulta [Cómo crear una plantilla](../../comunicaciones/comunicaciones/como-crear-una-plantilla.md).
* **Asunto:** campo obligatorio.
* **Selecciona reemplazo para insertar:** sirve para personalizar el mensaje. Por ejemplo, si eliges **Nombre**, se añade `[[Customer.Name]]`, que se cambia por el nombre de cada jugador al recibir el correo.
* **Cuerpo del mensaje:** escribe el texto. También puedes pegarlo desde otro documento o añadir imágenes. Para saber cómo, consulta [Cómo adjuntar una imagen a un mail](../../comunicaciones/comunicaciones/como-adjuntar-una-imagen-a-un-mail.md).
{% endstep %}

{% step %}
### Enviar

* Clica en **OK** para enviar el correo.
{% endstep %}
{% endstepper %}

Para comprobar si los correos han salido, consulta [Dónde ver el estado de envío de los correos](../../comunicaciones/comunicaciones/donde-ver-el-estado-de-envio-de-los-correos.md).
